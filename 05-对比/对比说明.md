# 工具对比

> 常见工具/方案的对比分析，帮助选型和决策。

## AI Agent 对比

### Hermes Agent vs Claude Code vs Codex CLI

| 维度 | Hermes Agent | Claude Code | Codex CLI |
|:-----|:-------------|:------------|:----------|
| **开放程度** | ⭐⭐⭐⭐⭐ 完全开源 | ⭐⭐ 闭源 | ⭐⭐⭐⭐ 部分开源 |
| **多模型支持** | ✅ 任意模型/提供商 | ❌ 仅 Claude | ❌ 仅 GPT |
| **可扩展性** | ✅ 技能 + 工具插件 | ⭐⭐ 有限 | ⭐⭐ 有限 |
| **MCP 支持** | ✅ 原生集成 | ✅ 支持 | ⭐ 有限 |
| **本地运行** | ✅ ChromaDB 本地 | ❌ 云端 | ❌ 云端 |
| **记忆系统** | ✅ MemOS 持久化 | ❌ 会话级 | ❌ 会话级 |
| **多平台** | ✅ 8+ 平台 | ❌ CLI 仅 | ❌ CLI 仅 |
| **技能市场** | ✅ agentskills.io | ❌ 无 | ❌ 无 |
| **上手难度** | ⭐⭐⭐ 中 | ⭐ 低 | ⭐⭐ 中低 |

**结论：** Hermes Agent 功能最完整、扩展性最好，但上手有一定门槛。

### 选型建议

| 场景 | 推荐 | 理由 |
|:-----|:-----|:-----|
| 个人知识管理 | **Hermes** | 记忆系统 + Obsidian 集成 |
| 快速编码助手 | **Claude Code** | 开箱即用，对话式编程 |
| 批量自动化 | **Hermes** | Cron Job + 技能编排 |
| 多平台消息 | **Hermes** | 8+ 平台原生支持 |
| 学习 AI 智能体 | **Hermes** | 开源可定制 |

## 嵌入模型对比

### BGE vs M3E vs all-MiniLM-L6-v2

| 维度 | BGE | M3E | all-MiniLM-L6-v2 |
|:-----|:-----|:-----|:-----------------|
| **开发者** | 智源研究院 | Moka | sentence-transformers |
| **中文能力** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **英文能力** | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| **速度** | 快 | 快 | **最快** |
| **内存占用** | ~180MB | ~180MB | **~90MB** |
| **维度** | 768 / 1024 | 768 / 1024 | 384 |
| **HuggingFace** | BAAI/bge-* | moka-ai/m3e-* | sentence-transformers/* |

**结论：** 中文为主用 BGE 或 M3E，英文为主用 all-MiniLM-L6-v2。本系统当前使用 all-MiniLM-L6-v2，因双核 CPU 内存有限。

## 网页抓取工具对比

### Camoufox vs crawl4ai vs scrapling

| 维度 | Camoufox | crawl4ai | scrapling |
|:-----|:---------|:---------|:----------|
| **定位** | 反爬抓取 | 批量抓取 | 轻量静态抓取 |
| **JS 渲染** | ✅ 完整 | ✅ 完整 | ❌ |
| **反爬能力** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ❌ |
| **速度** | 慢（启动浏览器） | 快 | **最快** |
| **资源消耗** | 高 | 中 | **最低** |
| **适用场景** | 微信/反爬页面 | 批量数据 | 纯静态页面 |

**选型建议：** 按页面复杂度选择，不要一上来就用 Camoufox。

## 记忆系统对比

### MemOS vs ChromaDB vs 纯文件

| 维度 | MemOS | ChromaDB | 纯文件 |
|:-----|:------|:---------|:-------|
| **定位** | 完整记忆系统 | 向量数据库 | 原始存储 |
| **智能去重** | ✅ LLM 判断 | ❌ 需自行实现 | ❌ |
| **混合检索** | ✅ FTS5 + 向量 + 时间 | ⭐ 仅向量检索 | ❌ |
| **自动预检索** | ✅ 每轮自动 | ❌ 需手动 | ❌ |
| **配置复杂度** | ⭐⭐⭐ 中 | ⭐⭐ 低 | ⭐ 最低 |
| **功能完整度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐ |

**结论：** MemOS 适合需要智能记忆管理的场景，ChromaDB 适合纯向量检索需求。
