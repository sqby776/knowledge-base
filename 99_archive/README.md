# 归档

> 已过期/已完成/不再维护的内容，保留以备参考。

## 归档说明

归档不是删除，是把"当前不需要但可能有用"的内容移到这里。

### 归档规则

| 条件 | 操作 |
|:-----|:-----|
| 项目已完成 | ✅ 移入归档 |
| 内容已过时 | ✅ 移入归档 + 标注已过时 |
| 内容被替代 | ✅ 移入归档 + 标注由新页面替代 |
| 测试/实验内容 | ✅ 可移入归档 |
| 不确定要不要删 | 🤔 先归档，三个月后清理 |

### 目录结构

```
99_archive/
├── projects/    # 已完成项目
├── notes/       # 过时笔记
├── tests/       # 测试/实验内容
└── README.md    # 本说明文件
```

### 归档文件标记

归档文件需在顶部添加标记：

```markdown
---
archived: true
archive_date: 2026-05-24
reason: 项目已完成 / 内容已过时 / 被替代
replaced_by: [新页面链接]
---
```
