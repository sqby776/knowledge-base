# LLM-as-Judge

## 概览

LLM-as-Judge 是一种评估方法，利用另一个 LLM 作为评估器来评判目标 LLM 的输出质量。适用于自动化评估、主观质量判断、大规模回归测试等场景。优势是效率高、可扩展，劣势是存在评估偏差。
