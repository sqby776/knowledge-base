# 数据序列化

数据序列化（Serialization）是将数据结构或对象状态转换为可存储或传输的格式的过程。反序列化（Deserialization）是其逆过程。

## 常见格式

| 格式 | 用途 | Python 库 |
|------|------|-----------|
| JSON | Web API、配置文件 | `json` |
| CSV | 表格数据、电子表格 | `csv` |
| Pickle | Python 对象持久化 | `pickle` |
| YAML | 配置文件 | `yaml` |
| XML | 文档、SOAP API | `xml` |
