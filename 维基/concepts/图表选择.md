# 图表选择

## 概览

Python 数据可视化中的图表类型选择方法论，包括折线图（趋势）、柱状图（对比）、饼图（占比）、散点图（相关）、箱线图（分布）、热力图（关联）等。核心原则：根据数据类型和分析目标选择最合适的图表，避免信息冗余或误导。

## 要点

- 趋势数据 → 折线图
- 分类对比 → 柱状图
- 分布展示 → 箱线图/直方图
- 相关性 → 散点图/热力图
- 占比 → 饼图/环形图（类别少时）
