# 路径管理

Python 中处理文件路径的概念和方法。

## 传统方式

`os.path.join()`、`os.path.abspath()`、`os.path.exists()`

## 现代方式（推荐）

使用 `pathlib` 模块的 `Path` 对象：

```python
from pathlib import Path
p = Path("/home/user/docs")
p / "file.txt"   # 路径拼接
p.exists()       # 是否存在
p.glob("*.md")   # 模式匹配
```
