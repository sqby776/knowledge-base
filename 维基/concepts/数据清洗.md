# 数据清洗

数据预处理过程中的关键步骤，将原始数据转换为可分析格式。

## 常见操作

| 操作 | 说明 | Pandas 方法 |
|------|------|-------------|
| 缺失值处理 | 删除或填充空值 | `dropna()` / `fillna()` |
| 重复值处理 | 删除重复行 | `drop_duplicates()` |
| 类型转换 | 转换数据类型 | `astype()` / `to_datetime()` |
| 异常值处理 | 识别和处理离群点 | 条件过滤 |
| 字符串清洗 | 去空格、替换、分割 | `str.strip()` / `str.replace()` |
