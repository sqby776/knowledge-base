# 绘图接口

Matplotlib 提供两种主要的绘图接口（API）。

## pyplot 接口（命令式）

```python
import matplotlib.pyplot as plt
plt.plot(x, y)
plt.title("标题")
plt.show()
```

类似 MATLAB 风格，自动管理 Figure 和 Axes。

## 面向对象接口

```python
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
ax.plot(x, y)
ax.set_title("标题")
plt.show()
```

更精细控制，适合复杂布局。
