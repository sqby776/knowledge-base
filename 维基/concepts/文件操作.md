# 文件操作

Python 中文件和目录操作的基本概念和方法。

## 核心模块

| 模块 | 用途 |
|------|------|
| `open()` | 内置文件读写函数 |
| `os` | 操作系统接口，文件和目录操作 |
| `pathlib` | 面向对象的文件系统路径操作 |
| `shutil` | 高级文件操作（复制、移动、删除） |
| `glob` | 文件模式匹配 |
