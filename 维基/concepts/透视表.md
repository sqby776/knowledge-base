# 透视表

数据透视表是一种交互式数据汇总工具，用于对数据进行分组、聚合和交叉分析。

## Pandas 实现

### pivot_table

```python
pd.pivot_table(df, values='销售额', index='地区', columns='季度', aggfunc='sum')
```

### 参数说明

| 参数 | 用途 |
|------|------|
| `values` | 要聚合的数值列 |
| `index` | 行索引（分组字段） |
| `columns` | 列索引（交叉字段） |
| `aggfunc` | 聚合函数：`sum`、`mean`、`count` 等 |
| `fill_value` | 缺失值填充 |
| `margins` | 是否显示总计 |
