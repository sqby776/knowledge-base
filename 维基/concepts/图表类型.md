# 图表类型

数据可视化中常用的图表类型，用于展示数据的不同维度和关系。

## 常见类型

| 图表类型 | 用途 | Matplotlib 函数 |
|----------|------|-----------------|
| 折线图 | 趋势变化 | `plot()` |
| 柱状图 | 分类对比 | `bar()` |
| 散点图 | 相关性分析 | `scatter()` |
| 饼图 | 占比分布 | `pie()` |
| 箱线图 | 数据分布 | `boxplot()` |
| 热力图 | 矩阵数据 | `imshow()` |
