# Agent Reach——AI Agent互联网能力扩展工具

## 摘要

Agent Reach（GitHub 23,672 Stars, MIT License）是一个开源Python项目， 解决AI Agent无法访问互联网的核心痛点——看不了YouTube、搜不了Twitter、 IP被屏蔽、需登录等。零配置免费使用：任意网页（Jina Reader转Markdown）、 YouTube/B站字幕提取、RSS订阅、微信公众号搜索、微博热搜、V2EX、抖音、 GitHub公开仓库、Exa AI语义搜索。部分平台需Cookie登录（小红书、Twitter/X、 Reddit、LinkedIn）。安装仅需一句话指令，Agent自动完成pip安装和配置。 安全提示：Cookie存储在~/.agent-reach/config.yaml（权限600），建议用专用小号。
