# OfficeCLI——Agent原生Office自动化工具

## 摘要

OfficeCLI（5000+⭐）是一个单二进制文件、零依赖的 Office 文档 CLI 工具，让 AI Agent 能直接创建、读取、修改 Word/PPT/Excel 文档，内置渲染引擎支持 HTML/SVG/截图实时预览。不需要安装 Office，不需要拼装 Python 库（python-docx/openpyxl/python-pptx）。核心思路：把 .docx/.xlsx/.pptx 变成 Agent 可以直接读写的对象。

## 可信度说明

公众号技术工具推荐文章，有 GitHub 项目数据，65%可信。

## 要点

- 单二进制文件，零依赖，无需安装 Office
- 内置渲染引擎，支持实时预览
- 创建/修改/预览/批量 四种模式
- officecli install 自动集成 Claude Code/Cursor/Codex
