# Python 数据可视化

## 摘要

RealPython 的数据可视化教程，介绍 Python 中主流可视化库的使用方法和最佳实践。

## 要点

- **Matplotlib**：底层绘图引擎，`pyplot` 接口
- **Seaborn**：基于 Matplotlib 的高级接口，内置统计图表
- **Plotly**：交互式图表库
- **可视化类型**：折线图、柱状图、散点图、热力图、箱线图等
- **最佳实践**：选择正确的图表类型传达信息，注意颜色对比，添加标题和标签
