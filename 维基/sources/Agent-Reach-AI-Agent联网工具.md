# Agent Reach——AI Agent互联网能力扩展工具

## 摘要

Agent Reach（23,672⭐）是一个 MIT 许可的开源脚手架，为 AI Agent 一键接入互联网能力——读网页、看 YouTube/B站视频字幕、刷小红书、搜 Twitter、查 RSS、看微博。通过统一的 pip install 安装，零配置使用部分平台（网页、YouTube、B站、RSS、GitHub等），部分平台需 Cookie 登录（小红书、Twitter、Reddit、LinkedIn）。所有后端开源，无需付费 API，完全免费可商用。
