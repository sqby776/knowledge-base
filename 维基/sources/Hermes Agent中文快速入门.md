# Hermes Agent 中文快速入门指南

## 摘要

中文社区快速入门指南。类Unix安装命令（含WSL2/Termux）：curl -fsSL https://res1.hermesagent.org.cn/install.sh | bash；Windows PowerShell：irm https://res1.hermesagent.org.cn/install.ps1 | iex。LLM提供商列表包括中国特有：z.ai/GLM、Kimi/Moonshot、MiniMax中国区、阿里云DashScope/Qwen、DeepSeek。快速命令参考：hermes/model/tools/setup/doctor/update/gateway。内置命令：/help、/tools、/model、/personality、/save、/new、/retry、/undo、/compress、/usage、/insights、/skills、/voice on、/stop。进阶探索：沙箱终端、消息平台连接、语音模式、技能安装、ACP编辑器集成、MCP服务器配置。
