# Agnes-2.0-Flash 多模态AI模型集成指南

## 摘要

Agnes 是多模态 AI 实验室，核心产品 Agnes-2.0-Flash 是免费开放的 OpenAI 兼容文本模型，在 Claw-Eval Agent 基准排名靠前。另提供 Agnes-Image-2.0-Flash（图片生成）和 Agnes-Video-2.0（视频生成），多模态基准全球第9。当前全部免费使用。支持直接集成到 OpenClaw、Hermes、WorkBuddy、Cherry Studio、Opencode、Codex++ 等8大 AI 工具。
