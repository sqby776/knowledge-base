# python-pptx 入门

## 摘要

python-pptx 官方文档快速入门。python-pptx 是一个用于创建和更新 Microsoft PowerPoint (.pptx) 文件的 Python 库。

## 要点

- **Presentation**：顶层对象，代表一个演示文稿
- **Slide**：幻灯片，属于 Presentation 的 slides 集合
- **Shapes**：幻灯片上的图形元素，包括文本框、表格、图片等
- **文本**：`TextFrame` 管理文本段落和运行
- **表格**：`Table` 支持单元格访问和格式设置
- **布局**：使用预定义布局或自定义创建幻灯片
