# Hermes Agent 官网核心信息

## 摘要

Hermes Agent是由Nous Research打造的自改进AI代理，标语为'唯一内置学习闭环的代理'。六大核心特性：无处不在（20+平台单一网关）、持久记忆、定时自动化、任务委派、网页浏览（搜索/浏览器/视觉/图片/TTS/多模型推理）、实验沙箱（6种后端）。部署方式包括本地/Docker/SSH/Daytona/Singularity/Modal，最低成本$5 VPS或Serverless。提供机器可读文档入口（llms.txt约17KB、llms-full.txt约1.8MB）。关键架构特性：学习闭环（记忆+自我提醒→自动创建技能→技能自改进→FTS5跨会话+LLM摘要→Honcho辩证用户建模），开放标准（兼容agentskills.io），MCP支持。
