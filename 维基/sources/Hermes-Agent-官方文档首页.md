## 摘要

Hermes Agent 官方文档的首页/入口页，由 Nous Research 构建。概述了 Hermes Agent 的核心定位——一个具有内置学习循环的自主 AI 代理，包含安装指引、快速链接表、关键特性列表等导航入口。

## 要点

- **安装方式**：Hermes Desktop（Windows/macOS）或一键脚本安装（Linux/macOS/WSL2/Android Termux）
- **快速入门**：安装后运行 `hermes setup --portal`，一次 OAuth 覆盖模型 + 四个 Tool Gateway 工具
- **核心定位**：不是 IDE 的编码助手，也不是单一 API 的聊天包装器，而是**自主 Agent**，可在 $5 VPS、GPU 集群或无服务器基础设施上运行
- **关键特性**：
  - 闭环学习：自主记忆管理、技能创建与自优化、FTS5 跨会话召回
  - 随处运行：6 种终端后端（本地/Docker/SSH/Daytona/Singularity/Modal）
  - 多平台：20+ 消息平台支持
  - 定时任务：内置 cron
  - 子代理并行：`delegate_task`
  - MCP 集成、语音模式、SOUL.md 个性定义
