# 矛盾追踪说明

## 用途

当新获取的资料与已有 wiki 页面中的旧判断产生冲突时，在此记录。

## 适用场景

- 政策法规更新导致旧条款失效
- 不同来源对同一事实的陈述不同
- 新研究推翻旧结论
- 数据/数字不一致

## 字段说明

- `credibility_a / credibility_b` — 两个矛盾来源各自的可信度评分（0-100%）
- `resolved: true/false` — 是否已有定论
- `conflict_type` — 数据冲突 / 结论冲突 / 政策变更

## 处理流程

1. 发现矛盾 → 创建 `YYYY-MM-DD_矛盾主题.md`
2. 记录双方观点和来源链接
3. 对比可信度
4. 标记 `resolved: false`
5. 在受影响的实体/概念页中添加 ⚠️ 标注
6. 人工确认后标记 `resolved: true`
