# Docker

## 概览

Docker 是一种容器化平台，用于开发、交付和运行应用程序。理解容器本质有助于更好地使用容器化部署。

## 关键信息

- build-your-own-x 提供从零实现 Docker 的指南
- 核心概念：命名空间、cgroups、联合文件系统、容器网络
- build-your-own-x 的 Docker 指南帮助理解：从进程隔离到容器编排的完整原理
