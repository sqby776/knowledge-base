# Plotly

Python 交互式可视化库，支持 Web 浏览器中的动态图表。

## 特点

- **交互式**：缩放、平移、悬停提示
- **多种输出**：HTML、Dash 应用、Jupyter Notebook
- **三维图表**：支持 3D 可视化
- **安装**：`pip install plotly`
