# Git

## 概览

Git 是目前最流行的分布式版本控制系统。理解 Git 对象模型是深入掌握版本控制的关键。

## 关键信息

- build-your-own-x 项目提供从零实现 Git 的 step-by-step 指南
- 从零写 Git 帮助理解：对象模型（blob/tree/commit）、分支机制、合并算法等底层原理
