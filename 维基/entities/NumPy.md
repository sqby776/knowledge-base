# NumPy

Python 数值计算基础库，提供多维数组对象和数学函数。

## 关键信息

- **核心对象**：ndarray（N 维数组）
- **功能**：数组运算、线性代数、傅里叶变换、随机数
- **安装**：`pip install numpy`
- **关系**：[[pandas]] 和 [[Matplotlib快速入门]] 都基于 NumPy
