# SQLite

## 概览

SQLite 是 Python 内置的轻量级关系数据库引擎，零部署、零运维，适合百万行数据级别的本地数据分析场景。

## 关键信息

- **Python 内置**: 无需额外安装
- **性能**: 百万行数据轻松处理
- **适合场景**: <100万行的本地数据分析
- **典型应用**: 经营分析数据基座（星型模型：10张维度表+7张事实表）
- **对比**: Excel（10万行瓶颈）→ SQLite（百万行轻松）→ MySQL（需服务器）→ 数据仓库（需团队）
