# Pandas

Python 数据分析核心库，提供 DataFrame 和 Series 数据结构。

## 关键信息

- **核心对象**：[[Series]]（一维）、DataFrame（二维）
- **功能**：数据读取、清洗、转换、聚合、可视化
- **适用场景**：数据分析和数据处理
- **安装**：`pip install pandas`

## 相关概念

- [[NumPy]] — 底层数值计算库
- [[数据清洗]] — 数据预处理方法
- [[时间序列]] — 时间序列分析
- [[透视表]] — 数据透视与聚合
