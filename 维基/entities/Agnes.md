# Agnes

## 概览

Agnes是多模态AI实验室，提供免费的OpenAI兼容文本、图像和视频生成模型。

## 关键信息

- 核心产品：Agnes-2.0-Flash（文本，Claw-Eval基准领先）、Agnes-Image-2.0-Flash（图像）、Agnes-Video-2.0（视频）
- 多模态基准全球第9
- 当前全部免费使用
- API Gateway: https://apihub.agnes-ai.com/v1
- 兼容OpenAI协议，支持8大Agent工具集成
- 官方网站: https://agnes-ai.com
