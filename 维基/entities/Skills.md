# Skills

## 概览

Skills（技能系统）是 Hermes Agent 的核心机制之一——存储操作流程（分步说明），遇到类似任务时自动调用。与记忆系统互补：记忆存储事实，技能存储操作过程。

## 关键信息

- **与记忆的区别**: 记忆存储事实（个人信息、项目偏好），技能存储操作流程（分步说明）
- **自动创建**: Agent 完成复杂任务后自动创建技能
- **自我改进**: 技能在使用中不断自我改进
- **兼容标准**: 兼容 agentskills.io 开放标准，通过 Skills Hub 分享
- **开源生态**: 技能市场包含社区贡献的丰富技能库
- **安装命令**: `hermes skills search <keyword> --source skills-sh`
