# Agent Reach

## 概览

Agent Reach是一个开源Python工具（MIT License），为AI Agent赋予互联网访问能力。

## 关键信息

- GitHub: 23,672 Stars, 1,999 Forks
- 零配置免费使用：网页阅读（Jina Reader）、YouTube/B站字幕、RSS订阅、微信公众号搜索、微博、V2EX、抖音、GitHub、Exa AI语义搜索
- Cookie登录功能：小红书、Twitter/X、Reddit、LinkedIn
- 安装指令：pip install agent-reach
- 安全建议：Cookie存于~/.agent-reach/config.yaml（权限600），建议用专用小号
- 不是框架而是脚手架，每个平台是独立上游工具
