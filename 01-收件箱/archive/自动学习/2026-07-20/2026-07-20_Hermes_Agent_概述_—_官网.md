# Hermes Agent 概述 — 官网

## 摘要

Hermes Agent 是由 Nous Research 开发的开源自改进 AI 代理。当前版本 v0.17.0 (MIT License)。
核心特性：
- 桌面应用（macOS/Windows/Linux）和 CLI 双入口
- 安装方式：curl 安装脚本 / PowerShell 安装脚本 / 桌面安装包
- 6 大核心功能：Lives Everywhere（多平台连接）、Persistent Memory（持久记忆）、Focused Automation（计划自动化）、Tasks Multiplied（子代理并行）、Browse the Web（网络搜索/浏览器自动化）、Isolated Sandboxing（隔离沙箱，5种后端）
- 付费层级：Free/Plus/Super/Ultra，通过 Nous Portal 提供 300+ 模型
- 官网使用 Next.js 构建，采用深色主题设计
