## 知识点摘要

### [文档概览] 完整文档结构

### [核心定位] 自我进化的 AI 智能体

不是 IDE 绑定的编程助手或单一 API 包装器，而是一个自主智能体，运行时间越长能力越强。可部署在 $5 VPS、GPU 集群或无服务器基础设施上

### [安装方式] 多种安装方式

Linux/macOS/WSL2/Android(Termux): curl 脚本安装；Windows (native): PowerShell 安装；也可下载 Hermes Desktop 桌面应用

### [快速启动] 最快路径

安装后运行 `hermes setup --portal`，一次 OAuth 覆盖模型 + 4个工具网关(网络搜索/图片生成/TTS/浏览器)
