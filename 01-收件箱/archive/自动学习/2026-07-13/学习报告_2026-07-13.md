## 3. 发现的关键更新与值得关注的变化

### 🔥 版本里程碑：v0.18.x 发布周期
- v0.18.2 于 **2026年7月8日** 发布，主要修复了 WhatsApp Baileys 桥接的依赖问题
- 从依赖 GitHub 固定 commit 改为使用已发布的 npm 包 `7.0.0-rc13`
- 完全版 Release Notes 将在 v0.19.0 发布

### 🆕 平台支持分级制度（新文档）
官方首次明确定义了 **Tier 1 / Tier 2 / 不支持** 三级平台支持策略：
- Tier 1 问题优先修复
- AUR、PyPI、Homebrew、macOS Intel 明确标记为**不支持**
- 这是重要的使用者期望管理

### 🆕 Windows 支持成熟
- 原生 PowerShell 安装（单行命令）
- 自动处理 uv, Python 3.11, Node.js, MinGit
- 无需 WSL 即可完整运行 CLI/Gateway/TUI
- 提供了 Windows Defender 误报解决方案

### 🆕 Blank Slate 模式
- 全新最小化安装模式，只开启 File Operations + Terminal
- 适合完全受控场景，按需启用工具

### 🆕 Nous Portal 一键配置
- `hermes setup --portal` 从零到运行，OAuth 一步搞定
- 覆盖模型 + Web搜索 + 图片生成 + TTS + 云浏览器

## 4. 对系统现状的优化建议

### 4.1 短期（立刻可做）

✅ **检查当前版本身份**：确认本地 Hermes 版本是否为 v0.18.2，旧版本考虑更新
✅ **利用 Nous Portal**：如果还在收集多个 API Key，`hermes setup --portal` 是最快路径
✅ **评估 Blank Slate 模式**：如果当前配置过于臃肿，可考虑最小化重建
