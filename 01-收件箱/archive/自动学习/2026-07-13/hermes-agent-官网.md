### 1. Connect — 无处不在的连接
- 支持 20+ 消息平台：Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI 等
- 一个 Agent，统一记忆，所有界面共享

### 2. Remember — 持久记忆
- 自主学习项目信息
- 自动生成技能（Skill）
- 永不忘记问题解决方案

### 3. Schedule — 聚焦自动化
- 自然语言定时任务
- 支持报告、备份、简报等场景无值守运行

### 4. Delegate — 任务倍增
- 隔离子 Agent（Subagent），拥有独立对话、终端和 Python RPC
- 零上下文开销的并行工作流

### 5. Search — 网络浏览
- Web 搜索、浏览器自动化、Vision、图片生成、TTS、多模型推理

### 6. Experiment — 隔离沙箱
- 五种后端：local, Docker, SSH, Singularity, Modal
- 容器加固和命名空间隔离
