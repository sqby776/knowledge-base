## 核心要点

### 1. 五层记忆架构
- **L1**: 短期上下文 — 当前会话对话窗口，实时推理用
- **L2**: MEMORY.md 持久化文件 — 结构化 Markdown，每次对话自动注入
- **L3**: FTS5 全文检索 ⭐ — SQLite FTS5 对历史对话建立索引，精准召回而非塞满上下文
- **L4**: 向量检索（语义层）— 弥补 FTS5 关键词匹配盲区
- **L5**: LLM 自动摘要压缩 — 长会话自动压缩，避免上下文膨胀

**关键洞察**: 纯向量检索对精确匹配效果差，FTS5 关键词检索补足短板。两者组合才是生产级方案。

### 2. Skill Loop 渐进式加载
- 复杂任务（5+ 工具调用）自动提炼成 SKILL.md
- Level 0: 先看到技能列表（标题+描述）
- Level 1: 确认需要时再加载完整内容
- 解决技能库扩大后的上下文爆炸问题
- 技能使用后可自动更新，闭环：做过→总结→改进→再用

### 3. Honcho 用户建模（黑格尔辩证法）
- **正题 Thesis**: 当前用户画像
- **反题 Antithesis**: 新对话中的矛盾/补充信息
- **合题 Synthesis**: LLM 融合生成更准确的新画像
- 每次对话结束自动更新，随时间越来越准确

### 4. MCP 异步桥接
- 核心矛盾：MCP 需要异步上下文，工具调用是同步的
- 解法：独立后台事件循环 + run_coroutine_threadsafe() 桥接
- 白名单机制：仅并行安全工具可同步执行
- 路径重叠检测：防止并行写冲突

### 5. Atropos RL 数据飞轮
- 内置批量轨迹生成
- 每次执行生成可用于 RL 训练的标准化轨迹
- 产品-飞轮-模型协同进化闭环
