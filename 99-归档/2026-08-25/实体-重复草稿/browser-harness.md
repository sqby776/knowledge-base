# browser-harness

## 定义

browser-harness — AI 浏览器自动化工具，通过 Chrome DevTools Protocol (CDP) 控制本地 Chrome，让 AI 像真人一样操作浏览器。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **CDP 控制** | 直接通过 DevTools Protocol 控制浏览器 |
| **本地 Chrome** | 使用用户本地已登录的 Chrome 浏览器 |
| **AI 驱动** | 由 LLM 指令驱动浏览器操作 |
| **Hermes 集成** | 作为 Hermes Agent 的浏览器自动化 Skill |

## 在本系统中的用途

- 微信公众号文章提取
- 网页交互与表单填写
- 动态页面内容获取
