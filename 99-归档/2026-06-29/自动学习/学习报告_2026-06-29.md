## 值得关注的更新与发现

### 🔥 高优先级
1. **Windows 原生安装成熟度提升** — 已不需要 WSL，PowerShell 一键安装，自带便携式 MinGit。但防病毒误报问题需要在文档中明确标注。
2. **Nous Portal 集成** — 一站式 OAuth 认证，覆盖模型+工具网关，降低新用户准入门槛。
3. **配置文件系统** — 支持多配置隔离、导出迁移，适合团队环境。
4. **国内镜像安装链路** — `res1.hermesagent.org.cn` 提供国内直连，解决 GitHub Raw 被墙问题。

### 📌 中等优先级
5. **多模型委派工作流（delegation config）**— 主模型和子 Agent 可以不同模型，灵活度很高。
6. **MCP 双向支持** — 既是客户端（消费外部工具），又是服务器（供 IDE 调用）。
7. **`/llms.txt` + `/llms-full.txt`** — 为 LLM 优化的文档入口，值得在其他项目推广。
8. **`execute_code` RPC 机制** — Python 脚本调用工具 API，零上下文损耗。

### ⚠️ 值得注意的差异
9. **中英文平台数字不一致**：英文 20+ 平台 vs 中文 14+ 平台 —— 中文站可能需要更新。
10. **工具数量不一致**：60+（英文官方文档）vs 47（中文网站）—— 中文站版本可能滞后。

## 新知识点摘要（区别于系统已有知识）

以下为本次学习中发现的、可能系统中尚未覆盖的知识点：

1. **按文件夹白名单防病毒** → 白名单文件夹而非文件哈希
2. **国内镜像安装域** → res1.hermesagent.org.cn
3. **delegation 多模型委派** → config.yaml 中 `delegation.model` + `delegation.provider`
4. **windows 安装位置** → `%LOCALAPPDATA%\hermes\`
5. **GitHub 上的 `hermes doctor` 诊断命令** → 排查问题
6. **配置文件导出/导入** → `hermes profile export/import`
7. **Termux 的 `.[termux]` 特殊 extra** → 因 voice 依赖中的 ctranslate2 没有 Android 轮子
8. **macOS 网关 PATH 陷阱** → launchd 使用精简 PATH，需重新运行 `hermes gateway install`
