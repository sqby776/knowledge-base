# Hermes Agent 社区五天新发现

来源: https://mp.weixin.qq.com/s/fwfxrjsf1LXf7ed8u9O10A
日期: 2026-06-03
类型: 社区生态清单

---

Hermes Agent 社区这几天彻底火了。GitTrend 整理了一份最新生态清单，全网程序员把 Hermes 玩出了五个全新花样，从 Docker 沙箱到零成本 AI 画图，一个比一个实用。

## 五个新技能

### 1. hermes-optimization-guide — 老鸟进阶圣经
把 LightRAG 知识图谱、Telegram 实时消息接入和 skill 自动创建打包成了最佳实践配置方案。给 Hermes 老手准备的调优秘籍。

### 2. hermes-agent-docker — 极简沙箱
一行命令拉起隔离环境，多实例互不干扰。"Agent 终于能安全关进笼子里了"。

### 3. codex-image — 零成本画师
本地 Codex.app 图像生成插件，零 API Key，完全免费。Telegram 或微信发指令，本地跑模型直接出图，隐私安全双拉满。

### 4. hermes-weather-plugin — 私人气象台
接入 NWS 和 NEXRAD 专业气象数据，实时预报加雷达图，比市面上任何天气预报 App 都好使。

### 5. execplan-skill — 持久战专家
带检查点、失败自动恢复和子任务编排的持久执行计划。Agent 跑复杂任务跑一半崩了就得重来，这个插件用快照加回滚解决了问题。

## 总结
五个项目全部开源，GitHub 上直接能搜到。Hermes 现在的生态已经不只是工具集合，更像一个可灵活组合的 Agent 操作系统。
