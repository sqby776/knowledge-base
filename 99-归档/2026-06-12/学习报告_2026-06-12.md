## 对系统现状的优化建议

### 1. 浏览器工具链恢复（高优先级）
当前 Hermes 浏览器会话（Camoufox）已断开，但进程仍在运行。建议:
- 重启 Hermes gateway 以恢复浏览器会话
- 或配置浏览器自动重连机制
- 对于自动化抓取任务，优先使用 `web_extract`（HTTP级别）作为主方案

### 2. 学习站点优先级调整
建议将学习站点按**信息价值和可提取性**排序:
- **优先**: 官网、文档、GitHub、中文网、FAQ（HTTP可提取）
- **中优先**: Agentskills.io、X推文（需搜索转载源）
- **低优先**: Discord、橙皮书、菜鸟教程（需浏览器渲染）

### 3. 信源分级执行
当前抓取结果已按信源分级:
- **Tier 1**: 官方文档、GitHub README
- **Tier 2**: 中文网文档、FAQ社区
- **Tier 3**: Agentskills.io 官方规范
- **Tier 4**: 百度百家号、优设网、X推文转载

### 4. 自动化学习频率
建议设定为**每周一次**自动学习，理由:
- Hermes 版本迭代快（两个月内从 28K→52K Star）
- 但重要更新可通过 GitHub Releases 监控更高效
- 社区类内容（FAQ、博客）更适合周更

### 5. 知识入库策略
