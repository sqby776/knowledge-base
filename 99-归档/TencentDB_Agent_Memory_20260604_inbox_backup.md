## 项目概览

**TencentDB Agent Memory** 是腾讯云数据库团队开源的 AI Agent 记忆系统，两个月内获得 4600+ Star。核心功能：给 AI Agent 装上长期和短期记忆。

**开源地址：** https://github.com/TencentCloud/TencentDB-Agent-Memory

---

## 核心架构：四层渐进式记忆

- **L0 - 原始对话：** 全量保留，一字不落。兜底用，随时可回查。
- **L1 - 原子事实：** 自动从对话中提取独立事实节点，打标签存储。
- **L2 - 场景聚类：** 相关原子事实按场景聚合，Markdown格式，人可直接读。
- **L3 - 用户画像：** 基于下面三层生成稳定用户画像，沉淀技术偏好、代码风格、常用工具链。

**关键设计：** 从顶层到原始证据有完整回溯路径，证据链不断裂。

## 短期记忆优化

- **符号化记忆：** 完整日志卸载到外部文件
- **Mermaid 图：** 紧凑任务状态图塞入上下文
- **效果：** Token 消耗直降超 50%，任务完成率反升 23%

## 安装使用

**OpenClaw 插件：**
```bash
openclaw plugins install @tencentdb-agent-memory/memory-tencentdb
```

**Hermes Agent：** 提供 Docker 一体化镜像，`docker pull` 下来就能跑。

**存储后端：** 默认本地 SQLite + sqlite-vec，零配置开箱即用。

## 集成建议

**评级：P0 - 强烈推荐集成**

理由：
1. 记忆双轨架构（符号化+向量）与 Cognee 互补
2. 短期记忆压缩方案（Mermaid图）可直接借鉴到 Hermes 的 context 管理
3. 四层架构设计精妙，回溯路径完整
4. 已验证数据优秀，事实召回提升显著
5. Hermes 有 Docker 镜像，集成门槛低
