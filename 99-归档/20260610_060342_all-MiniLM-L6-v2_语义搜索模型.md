## 核心要点

### 模型概况
- **模型**: `sentence-transformers/all-MiniLM-L6-v2`
- **主权重**: 约 90.9MB
- **量化 ONNX**: 约 23MB
- **输出**: 384 维向量
- **训练数据**: 11.7 亿+ sentence pairs
- **截断**: 默认超过 256 word pieces
- **下载量**: 253,044,030 次/月（Hugging Face）

### 工作原理
```
输入句子/短段落 → 模型输出 384 维向量 → 向量库按距离找相似内容 → 候选交给重排模型/大模型
```

### 典型应用场景
1. **客服 FAQ**: 用户不按标准问题提问也能召回
2. **知识库搜索**: 文档标题没写关键词也能被找到
3. **RAG 检索**: 从文档库里捞候选段落
4. **相似问题合并**: 重复工单、重复需求归类
5. **商品/内容推荐**: 用描述文本做相似匹配

### 关键认知
- **召回烂，后面全是糊弄学** — 大多数 RAG 失败不在大模型，而在第一步召回质量
- 它只负责"相似"，不负责"正确"，后面需要重排/规则/评估集
- 90.9MB 比商业 embedding API 更适合本地试错

### 局限性
- 英文语料背景更强，中文业务不要裸奔上线
- 长文不能整篇硬塞（超 256 word pieces 截断）
- 适合召回，不适合最终判断
- 大规模需要向量库、缓存、批处理

### 使用示例
```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
embeddings = model.encode(["发票怎么重开", "如何重新开票"])
```
