# 装了80个Skill之后我才看懂，这10个必装的，不是来替代你的，是用来复制你的

作者：Dr.Joyi | 像素与咖啡时光 | 2026年6月1日

## 核心观点

装了80多个Skill之后才发现，每天真正在用的，5个都不到。

看到一张图说中文内容创作者的10个必装Skill，第一反应是这玩意用处不大。但点进去看了作者——宝玉、归藏、卡兹克，全是真人名，X上天天发推那几个。

这10个东西，没有一个是哪家大公司做出来产品。是几个活生生的内容创作者，把自己每天在用的一套手艺，从脑子里扒下来，写成的文字，开源了。

**关键洞察：Skill 不是一个功能按钮。它是某个真人，把自己刻在肌肉里的工作习惯，复制了一份，免费摆在那儿，等你拿走。**

## 十个Skill逐一拆解

### 一、内容生产工作流 — 把别人的脑子，借给你用

#### 1. dbskill — 选题诊断
帮你在动笔前做选题判断：这个题好不好、爆款标题怎么起、怎么把干巴巴的商业点讲成人话。
- **价值**：偶尔救命，救得很关键
- **边界**：能帮你判断一个题好不好，帮不了你**想出**那个只有你能想出来的题。框架可以复制，灵感不行。

#### 2. content-research-writer — 速度100倍的实习生
资料搜集、主题搜罗、引用整理，连初稿都能拉一版。人肉做要小半天，它几分钟跑完还带来源。
- **关键教训**：有一次让它查政策风险，报告做得漂漂亮亮，结果来源是2023年旧文章。**它给每一条结论，都得回去看来源的日期。它是实习生，不是法律顾问。速度快100倍是真的，但快不等于对。**

#### 3. NotebookLM Skill — 把你的资料库盘活
基于你已经攒下的知识库来写，把零散的笔记、PDF、文章理出一条脉络。让一堆死资料活过来，能被问、能被串。
- **前提**：你得先有一个像样的资料库。库里是空的，它再强也是巧妇难为无米之炊。
- **复制的不是别人的手艺，而是让你过去的积累产生复利的能力。**

#### 4. khazix-skills — 微信公众号个人媒体王者
数字生命卡兹克开源的一整套：khazix-writer（写长文）、hv-analysis（横向深度研究+排版精美PDF）、选题判断框架。
- **核心认知**：卡兹克这套Skill一个字都帮不了你选题。得你自己挑。这是**复制和替代的第一个分界线**。
- 它自己在说明书里写：这个Skill是一个文风生成器，不是替代你思考的工具。

#### 5. Humanizer-zh — 它能看见你已经习惯到看不见的东西
归藏做的中文版，基于维基百科整理的AI写作特征清单做本地化。专治机器才会犯的毛病：浮夸的象征、三段式排比、不必要的连接词、过度中性听起来像没有体温的腔调。
- **真正的价值**：不是那个百分比。它真正干的事，是**能看到你已经习惯到看不见的东西**。一个写几年AI内容的人，最可怕的不是写得差，是你的语感本身已经被AI腐蚀了味。Humanizer 就是那双没被污染的眼睛。

### 二、视觉包装与分发 — 宝玉和归藏两人撑起来的大半条命脉

#### 6. ian-xiaohei-illustrations — 给正文配手绘小黑的插图
给文章正文配小黑那种风格的插图，让纯文字稿子读起来有呼吸感。
- 作者自己承认没真正接入流程，因为文风偏长偏密，还没想清楚插图该怎么塞进去不打断节奏。

#### 7. baoyu-skills — 把封面的玄学，拆成了6个旋钮
宝玉做的一整套，github上十几k的星。做封面的、做信息图的都有。
- **最有价值的地方**：他把封面这个玄学，拆成了能单独调的维度：构图、配色、渲染、文字层级、情绪强度。
- **教训**：有次出图60秒没回来，以为白跑。后来才明白：**超时不等于失败。任务在后台还在跑，只要带一个resume参数回去找它，一分不重复扣。**

#### 8. guizang-social-card — 长文拆碎了，重新长成卡片
归藏做的。把长内容转成小红书那种一格格图文卡片，或公众号那种21:9配1:1封面对。
- **价值**：长文写完之后的分发苦力活，它替你扛了。背后是归藏自己的审美在撑着。

#### 9. guizang-ppt-skill — 把观点立成一套能讲的slides
归藏的另一个兄弟。照着自己几场线下分享榨出来的，每一个踩过的坑都写进了checklist里。
- **定位**：不是主力，赶时间时是王牌。

#### 10. html-anything — 万物的最后一公里
Markdown → HTML → PNG。不创造内容，它让你写的东西能以正确的形状，落到该落的地方。
- **平时存在感为零，关键时刻能救命。**

## 核心认知升级

这10个Skill，没有一个是从天上掉下来的。每一个背后，都有一个真名真人。

你把它们装上的那一刻，发生的事情，不是你多了几个功能。**是你把这几个人刻在身体里的一部分手艺，复制了一份，长进了自己的工具栏。**

这**不是替代**，是**复制**。

框架可以复制，灵感不行。工具会卡顿，会超时，会心跳一紧。但只要你懂它的脾气，它就是你手中最快的牌。

一个开源工具，亲口告诉你它替代不了你——我觉得这比任何宣传都动人。
