# 文档资源索引

## 说明

此目录存放处理后的文档文件（Word/Excel/PPT/PDF），用于：
- 自动化脚本的输出结果
- 模板文档
- 示例文件

## 子目录

| 目录 | 用途 |
|:-----|:-----|
| `reports/` | 自动生成的报告文档 |
| `examples/` | 示例模板文件 |
| `templates/` | 可复用的模板文件 |

## 使用规范

1. 自动化脚本输出放在 `reports/`
2. 示例文件放在 `examples/`
3. 模板文件放在 `templates/`
4. 在 `03_resources/links/` 添加对应链接索引
