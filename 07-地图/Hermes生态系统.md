## 🔄 工作流模式

### 单代理模式

```
User → Hermes → [LLM + Tools] → Response → User
```

### 子代理模式

```
User → Hermes (orchestrator)
           │
           ├──▶ Subagent A (leaf) → Result A
           ├──▶ Subagent B (leaf) → Result B
           └──▶ Subagent C (orchestrator) → Sub-subagents → Result C
           
           ↓
      Summary → User
```

### Cron 模式

```
Scheduler → Cron Job → Agent (fresh session) → Deliver to target
     │                                            │
     │                                            ▼
     │                                      User/Channel
     │
     └── Schedule: '30m', 'every 2h', '0 9 * * *', ISO timestamp
```

### 多代理协作模式

```
Agent A (backend) ← context → Agent B (frontend)
     │                              │
     └────── tmux worktree ────────┘
              (isolated git)
```

## 📊 配置层级

```
┌─────────────────────────────────────────────────────────────────┐
│                 CONFIGURATION HIERARCHY                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ~/.hermes/config.yaml          ← 主配置 (模型/工具/安全/显示)  │
│  ~/.hermes/.env                 ← 环境变量 (API 密钥)           │
│  ~/.hermes/profiles/<name>/     ← 多配置文件 (隔离技能/记忆)    │
│  ~/.hermes/auth.json            ← OAuth tokens + 凭证池         │
│  ~/.hermes/shell-hooks-allowlist.json ← Shell 钩子白名单        │
│                                                                 │
```

## 🚀 快速启动

```bash
# 交互式启动
hermes

# 单查询模式
hermes chat -q "你的问题"

# 配置向导
hermes setup

# 健康检查
hermes doctor

# 模型选择
hermes model

# 工具管理
hermes tools

# 技能管理
hermes skills list

# 状态检查
hermes status
```
