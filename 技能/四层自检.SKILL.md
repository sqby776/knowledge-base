# 四层自检金字塔

> 来源：《数字生命卡兹克文风复刻 skill 深度拆解》
> 关键区分：L1-L3 可让 AI 自检，L4 必须人来判断。

---

## 金字塔结构

```
        L4 像不像人
       ┌─────────────┐
      L3 表达清晰     │
     ┌───────────────┐
    L2 逻辑自洽      │
   ┌─────────────────┐
  L1 事实核验         │
  └─────────────────┘
```

---

## L1：事实核验

**谁来做**：AI 自检 ✅

**检查项**

| 检查点 | 方法 |
|--------|------|
| 日期是否正确 | 逐个核对事件时间线 |
| 数据来源是否准确 | 检查引用出处 |
| 人名是否写对 | 逐个人名核对 |
| 引用是否准确 | 回原文核查，不能靠记忆 |
| 统计数字是否经得起推敲 | 检查原始出处 |

**执行方式**：把文章发给 AI，要求 "逐条核对 L1，标出任何存疑的事实"。

---

## L2：逻辑自洽

**谁来做**：AI 自检 ✅

**检查项**

| 检查点 | 信号 |
|--------|------|
| 段落之间是否有跳跃性断言 | 上一个论点和下一个论点之间缺了连接 |
| 前后是否有自相矛盾 | 前文说 A，后文在暗示非 A |
| 论据是否真的支持论点 | 用这个例子真的能证明那个观点吗？ |
| 因果关系是否成立 | 相关性 ≠ 因果性 |

**执行方式**：把文章发给 AI，要求 "找出所有逻辑跳跃和因果缺失的地方"。

---

## L3：表达清晰

**谁来做**：AI 自检 ✅

**检查项**

| 检查点 | 修正方向 |
|--------|---------|
| 冗余词 | "实际上" "其实" "在我看来" 删除 |
| 长句未断句 | 超过 30 字的句子拆分 |
| 黑话/行业术语 | 读者看不懂的词替换或加注释 |
| 段落过长 | 单段超过 200 字考虑拆分 |
| 标题和正文的关系 | 标题是否兑现了读者的预期？ |

**执行方式**：把文章发给 AI，要求 "逐段做表达润色，但要保留原文语气"。

---

## L4：像不像人

**谁来做**：**必须人来判断** ❌（AI 帮不了你）

**核心问题**

> 真的有人会这么说吗？

**检查维度**

| 维度 | 具体问法 |
|------|---------|
| 语气自然度 | 读 aloud，会不会觉得别扭？ |
| 情绪真实性 | 这里的情绪是真实感受还是"应该有的情绪"？ |
| 金句的人工感 | 金句是顺势写出来的，还是硬凑的？ |
| 整体节奏 | 读完整篇，有没有"太快"或"太慢"的感觉？ |

**判断方法**：读完文章后，问自己一个问题——**如果把这篇文章匿名发布，熟人看了会不会知道这是你写的？**

- 会 → 通过了 L4
- 不会，会觉得"不像你" → 还需要打磨

---

## 完整发布流程

```
写完初稿
    ↓
[AI] L1 事实核验 → 修正所有事实错误
    ↓
[AI] L2 逻辑自检 → 补全逻辑跳跃
    ↓
[AI] L3 表达润色 → 删除冗余、拆分长句
    ↓
[人] L4 朗读检验 → 像不像人？像 → 发布，不像 → 回到 L1
```

**不能跳级**。L4 通不过，不要跳过发出去。时间不够宁可暂缓。
