# Agentic RAG

## 定义

Agentic RAG（代理增强检索生成）—— RAG 的进阶形态，引入 Agent 自主决策能力，让系统能够自主决定检索策略、执行多轮检索、并进行自我修正。

## 与基础 RAG 的区别

| 维度 | 基础 RAG | Agentic RAG |
|:----|:----|:----|
| **检索策略** | 固定、单次 | 自主决定、多轮 |
| **错误处理** | 无法自我修正 | 可检测错误并修正 |
| **复杂度** | 简单流水线 | 多步骤决策 |
| **灵活性** | 低 | 高 |

## 核心能力

1. **自主检索决策** — Agent 判断是否需要检索、检索什么、检索多少次
2. **多跳检索** — 通过多次检索逐步逼近答案
3. **自我修正** — 检测生成结果的质量，必要时重新检索
4. **工具调用** — 可调用搜索 API、数据库、代码解释器等

## 工作流程

```
用户提问
    ↓
Agent 分析：需要检索吗？
    ↓
是 → 制定检索策略 → 执行检索 → 评估结果
    ↓                    ↓
否 ← 直接生成 ← 结果不足？
    ↓
生成答案 → 质量评估 → 需要修正？
    ↓                    ↓
输出答案 ← 否 ← 是 → 重新检索/修正
```

## 应用场景

- 复杂问题需要多源信息整合
- 领域专业问题需要多次验证
- 实时信息需要动态检索
- 长尾问题需要灵活策略
