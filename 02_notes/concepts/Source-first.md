# Source-first

## 定义

Source-first（源头优先）—— 知识管理中的核心原则，强调原始资料（Source）的优先级高于任何衍生内容。

## 核心原则

| 原则 | 说明 |
|:-----|:-----|
| **原始资料只读** | `01_inbox/` 中的原始资料只追加不修改 |
| **可追溯性** | 每个知识节点必须能追溯到原始来源 |
| **AI 不改写原文** | 让 AI 提取知识，但不修改原始资料 |

## 为什么需要 Source-first

```
原始资料（Source）
    ↓
AI 编译/提取
    ↓
知识节点（Derived）
    ↓
使用/引用

如果原始资料被修改 → 知识节点失去可信度
```

## 目录分工

| 目录 | 角色 | 规则 |
|:-----|:-----|:-----|
| `01_inbox/` | 原始资料 | 只追加，不修改 |
| `02_notes/` | 衍生知识 | 可编辑，需标注来源 |
| `03_resources/` | 参考资料 | 可编辑，需标注来源 |

## 引用规范

```markdown
# 正确格式
> 来源：[[01_inbox/articles/文章标题]]

# 或
> 来源：[[RAG]] 技术简析

# 错误格式（无来源）
RAG 是一种检索增强生成技术。
```

## 与质量规则的关系

- **待验证标记**：`> [!WARNING] 待验证` — 标注不确定的内容
- **来源标注**：所有结论必须标注来源
- **原始资料保护**：不让 AI 改写 `01_inbox/` 中的文件
