# 向量数据库

## 定义

向量数据库是专门用于存储和检索向量嵌入（Embedding）的数据库，是 [[RAG]] 系统的核心组件之一。

## 核心功能

1. **向量存储** — 高效存储高维向量
2. **相似度检索** — 根据查询向量快速找到最相似的向量
3. **元数据过滤** — 支持结合元数据进行混合检索

## 常见方案

| 数据库 | 类型 | 特点 |
|:----|:----|:----|
| [[Chroma]] | 轻量级 | 本地运行，适合开发测试 |
| [[Milvus]] | 分布式 | 企业级，支持大规模数据 |
| [[Pinecone]] | 云服务 | 全托管，易用但收费 |
| [[Qdrant]] | 开源 | 高性能，支持过滤 |

## 在 RAG 中的位置

```
文档 → 文本分块 → 嵌入模型 → 向量 → 向量数据库
                                      ↓
用户提问 → 嵌入模型 → 查询向量 → 相似度检索 → 相关文档块
```
