# Hermes Agent

## 定义

商汤科技开发的自主 AI 智能体框架，具备工具调用、技能管理、记忆系统、多平台连接能力。

## 核心能力

| 能力 | 说明 |
|:----|:----|
| **工具集** | terminal、file、browser、vision、web_search、delegate_task 等 |
| **技能系统** | SKILL.md 可复用工作流，支持创建/更新/删除 |
| **记忆系统** | MemOS（MemPalace）— 智能去重、混合检索、自动预检索 |
| **多平台** | Feishu、Telegram、Discord、本地文件等 |
| **Cron Job** | 定时任务调度，支持自主执行 |

## 在本知识库中的角色

- **知识编译器**：把文章编译成概念/实体/MOC 页面
- **自动化引擎**：定时抓取、自动分类、自动汇报
- **双链构建者**：强制使用 wikilink 建立知识网络
