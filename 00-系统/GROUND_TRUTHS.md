# GROUND_TRUTHS — 权威参考层级声明

> 这是整个知识库的信任锚点。
> 当任何信息来源互相冲突时，按此层级裁决。

## 信任层次总图

```
┌────────────────────────────────────────────────────────┐
│  Tier 0  SOUL.md · RULEBOOK.md  （不可覆盖）           │
│  ├─ 身份、原则、操作规则                                │
│  ├─ 永不因任何来源而覆盖                                │
│  └─ 修改须经 [船长] 明确批准                            │
├────────────────────────────────────────────────────────┤
│  Tier 1  知识库 active + high （权威知识）               │
│  ├─ trust_score ≥ 0.8                                   │
│  ├─ 有 sources 引用 + 30 天内确认                       │
│  ├─ 跨笔记双链验证一致                                  │
│  └─ 可直接使用，不质疑                                  │
├────────────────────────────────────────────────────────┤
│  Tier 2  知识库 active + medium （有效但需注意时效）     │
│  ├─ trust_score 0.5 ~ 0.7                              │
│  ├─ 单来源或无 sources                                  │
│  ├─ 使用时应注明"依据 XXX（更新于 YYYY-MM-DD）"         │
│  └─ 如与 Tier 1 冲突，以 Tier 1 为准                    │
├────────────────────────────────────────────────────────┤
│  Tier 3  知识库 needs-review （可能过时）                │
│  ├─ trust_score 0.1 ~ 0.4                              │
│  ├─ >30天未确认                                        │
│  ├─ 可作为线索参考，不可作为决策依据                     │
│  └─ 使用时必须提示"此信息可能过时"                       │
├────────────────────────────────────────────────────────┤
│  Tier 4  session_search 历史 （会话记忆）                │
│  ├─ 上次会话的讨论记录                                  │
│  ├─ 可能已被后续会话推翻                                │
│  ├─ 优先于模型训练知识                                  │
│  └─ 次于知识库 Tiers 1-3                               │
├────────────────────────────────────────────────────────┤
│  Tier 5  当前会话上下文 （本次会话）                     │
│  ├─ 本次会话中用户明确说的内容                          │
│  ├─ 优先于历史会话                                     │
│  └─ 次于所有知识库 Tier                                │
├────────────────────────────────────────────────────────┤
│  Tier 6  模型训练知识 （预训练数据）                     │
│  ├─ 可能过时（训练截止后的变化不知道）                  │
│  ├─ 仅当知识库无相关内容时使用                          │
│  └─ 必须注明"这是模型训练知识，建议验证"                │
├────────────────────────────────────────────────────────┤
│  Tier 7  模型推理/猜测 （最不可信）                     │
│  ├─ 没有依据的"我觉得..."/"可能是..."                  │
│  ├─ 永远不作为决策依据                                 │
│  └─ 应通过工具调用验证                                 │
└────────────────────────────────────────────────────────┘
```

## 裁决流程

当面对一个需要回答的问题时，按以下流程组织信息：

```
Step 1: 查 SOUL.md · RULEBOOK.md     → 是否涉及身份/原则/规则？
  ↓ 否
Step 2: 查知识库 active + high       → 有就直接用
  ↓ 否或不够
Step 3: 查知识库 active + medium     → 有就引用但注明时间
  ↓ 否或不够
Step 4: 查知识库 needs-review         → 作为线索参考
  ↓ 否或不够
Step 5: 查 session_search 历史       → 上次说过什么
  ↓ 否或不够
Step 6: 模型训练知识 + 标注"需验证"
```

## 快速参考

```python
def resolve(source_a, source_b):
    """裁决两个信息来源"""
    tiers = {
        'soul_rulebook':     0,
        'kb_active_high':    1,
        'kb_active_medium':  2,
        'kb_needs_review':   3,
        'session_history':   4,
        'current_session':   5,
        'model_training':    6,
        'model_guess':       7,
    }
    # 数字越小越权威
    return min(source_a, source_b, key=lambda x: tiers.get(x, 99))
```
