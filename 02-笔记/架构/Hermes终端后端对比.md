# Hermes 终端后端对比

| 后端 | 适用场景 | 持久化 | 成本 |
|------|---------|--------|------|
| 本地 | 开发调试 | 无 | 免费 |
| Docker | 隔离环境 | 容器级 | 低 |
| SSH | 远程服务器 | 会话级 | 低 |
| Daytona | 云开发环境 | 自动保存 | 按量 |
| Singularity | HPC 集群 | 集群级 | 按量 |
| Modal | 无服务器 | 自动休眠唤醒 | 按调用量 |

## 无服务器持久化 (Daytona/Modal)
- 空闲自动休眠，按需唤醒
- 适合低频使用场景，成本优化
- 唤醒延迟: 5-15 秒

## 最佳实践
- 日常开发: 本地后端
- 团队协作: Daytona/Modal
- 高性能计算: Singularity
- CI/CD 集成: Docker
