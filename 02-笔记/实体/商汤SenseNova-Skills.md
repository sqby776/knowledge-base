# 商汤 SenseNova-Skills

## 定义

商汤 SenseNova-Skills — 商汤科技推出的办公自动化 Skill 系统，涵盖 PPT 生成、数据分析、文档处理等多个领域的 AI 技能。

## 核心技能

| 技能 | 功能 |
|:-----|:-----|
| sn-ppt-entry | PPT 初级生成 |
| sn-ppt-standard | PPT 标准生成 |
| sn-ppt-creative | PPT 创意生成 |
| sn-ppt-doctor | PPT 智能优化 |
| sn-da-excel-workflow | Excel 数据分析工作流 |
| sn-image-base | 基础图像处理 |
| sn-infographic | 信息图生成 |
| sn-deep-research | 深度研究分析 |

## 在本系统中的用途

- 作为 Hermes Skills 的补充技能来源
- 办公自动化场景增强

## 来源

- 商汤科技 Hermes 技能市场
