# 📱 手机同步配置指南

## 目标
手机编辑知识库 → 自动同步到电脑

## 原理
```
手机编辑 → Git commit → Git push → GitHub
                                    ↓
电脑 Git pull ← Git push ← GitHub
```

---

## 一、手机端配置步骤

### 1. 安装 Obsidian
- App Store / Google Play 搜索 "Obsidian"
- 安装并打开

### 2. 克隆 GitHub 仓库
1. 打开 Obsidian，点击 "Open another vault"
2. 选择 "Clone an existing vault"
3. 输入仓库地址：`https://github.com/sqby776/knowledge-base.git`
4. 选择本地保存路径（建议新建一个文件夹）
5. 输入 GitHub 用户名和密码（或 Token）

### 3. 配置 Git 插件
1. 进入设置 → Community plugins → 关闭 "Safe mode"
2. 搜索 "Git" 并安装
3. 启用 Git 插件

### 4. 设置自动同步
在 Git 插件设置中配置：

| 设置项 | 推荐值 |
|--------|--------|
| Auto Commit | ✅ 开启 |
| Auto Pull | ✅ 开启 |
| Auto Push | ✅ 开启 |
| Commit Interval | 5 分钟 |
| Pull Interval | 5 分钟 |
| Commit on File Save | ✅ 开启 |

---

## 二、电脑端配置步骤

### 1. 打开 Obsidian
- 打开知识库：`~/workspace/knowledge/`

### 2. 启用 Git 插件
1. 进入设置 → Community plugins
2. 找到 "Git" 并启用
3. 如果未安装，先点击 "Browse" 搜索安装

### 3. 配置自动同步
在 Git 插件设置中配置：

| 设置项 | 推荐值 |
|--------|--------|
| Auto Commit | ✅ 开启 |
| Auto Pull | ✅ 开启 |
| Auto Push | ✅ 开启 |
| Commit Interval | 5 分钟 |
| Pull Interval | 5 分钟 |
| Commit on File Save | ✅ 开启 |

### 4. 验证配置
```bash
cd ~/workspace/knowledge
git status
git remote -v
```

## 三、同步流程示例

### 场景：手机上写了一篇新笔记

```
14:00  手机创建新笔记 "Excel 自动化技巧.md"
14:01  Git 自动 commit（本地）
14:01  Git 自动 push → GitHub
14:05  电脑 Git 自动 pull ← GitHub
14:05  电脑 Obsidian 刷新，看到新笔记 ✅
```

### 场景：电脑上修改了笔记

```
15:00  电脑修改 "Excel 自动化技巧.md"
15:01  Git 自动 commit（本地）
15:01  Git 自动 push → GitHub
15:05  手机 Git 自动 pull ← GitHub
15:05  手机 Obsidian 刷新，看到修改 ✅
```

## 四、注意事项

### ⚠️ 同步冲突
如果手机和电脑**同时修改**了同一个文件：

1. Git 会提示冲突
2. 需要手动选择保留哪个版本
3. **建议**：避免同时编辑同一文件

### ⚠️ 网络要求
- 手机需要能访问 GitHub
- 国内网络可能需要代理
- 如果 GitHub 访问慢，考虑用坚果云替代

### ⚠️ 大文件
- Git 不适合大文件（>10MB）
- 图片、PDF 建议用其他同步方式

### 方法 2：查看 Git 日志
```bash
cd ~/workspace/knowledge

```

## 六、故障排查

| 问题 | 解决方法 |
|------|----------|
| 手机无法连接 GitHub | 检查网络，可能需要代理 |
| Git 插件不工作 | 重启 Obsidian，重新启用插件 |
| 同步冲突 | 手动解决冲突，保留需要的版本 |
| 文件没同步 | 检查 Git 插件设置，手动点击 Push/Pull |

## 七、备选方案

如果 GitHub 同步不方便，可以考虑：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **坚果云** | 国内访问快 | 需要注册 |
| **Syncthing** | 点对点，隐私好 | 配置复杂 |
