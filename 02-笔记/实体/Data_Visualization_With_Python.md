# Data Visualization With Python

> Real Python 的 Python 数据可视化学习路径（Learning Path），2026-08-08 更新

## 路径目标

完成本路径后，你将能够：

- 直接从 pandas 绘图并创建直方图
- 使用 Matplotlib 和 Seaborn 构建详细可视化
- 使用 Bokeh 创建交互式图表、用 ggplot 绘制样式化图表
- 使用 Dash 构建数据可视化 Web 应用
- 使用 Folium 生成 Web 地图

## 适用人群

面向希望在报告、仪表盘或 Web 应用中呈现数据的 Python 开发者。需要基础 Python 和一定的数据结构知识。

## 学习路径（10 个资源）

### 1. 数据可视化入门
利用 NumPy、Matplotlib、pandas、Seaborn 学习创建直方图和图表的基础。

1. **Plot With pandas: Python Data Visualization Basics** — 了解 pandas 提供的各种绘图类型、如何用于数据探索、以及哪种图表最适合特定场景
2. **Histogram Plotting: NumPy, Matplotlib, Pandas & Seaborn** — 用 Python 科学栈构建生产级、可展示的直方图

### 2. 数据可视化库深入学习
深入 Matplotlib 绘图、Bokeh 交互可视化、ggplot 的图形语法。

3. **Python Plotting With Matplotlib** — 从理论和实践示例学习 Matplotlib 绘图
4. **Improve Matplotlib With Style Sheets & Python Async for the Web** — 样式表与 Web 异步
5. **Using plt.scatter() to Visualize Data in Python** — 用 Matplotlib 的 plt.scatter() 创建散点图
6. **Visualizing Data in Python With Seaborn** — 用 seaborn 生成统计数据分析图，涵盖经典接口和现代 objects 接口

### 3. 交互式应用与地图
用 Bokeh 创建交互式图表、用 Dash 构建 Web 应用、用 Folium 生成交互式地图。

7. **Interactive Data Visualization With Bokeh** — 交互式数据可视化
