# Matplotlib

## 定义

Matplotlib — Python 最流行的数据可视化库，支持折线图、柱状图、散点图、饼图、等高线图等几乎所有图表类型。

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| **多图表类型** | 线图、柱状图、散点图、饼图、热力图等 |
| **自定义样式** | 颜色、字体、标签、图例等全可自定义 |
| **子图布局** | `subplot` / `subplots` 创建多子图 |
| **动画** | `FuncAnimation` 创建动画图表 |
| **交互模式** | 缩放、平移、数据点提示 |

## 与其他库的关系

- Seaborn — 基于 Matplotlib 的高级统计绘图
- Bokeh — 交互式可视化替代方案
- Pandas — 内置的 `.plot()` 基于 Matplotlib
