# Matplotlib

## 概览

Python 最基础的绘图库，提供类似 MATLAB 的交互式绘图接口。

## 关键信息

- **pyplot**：命令式绘图接口，`plt.plot()`/`plt.scatter()`/`plt.bar()`
- **Figure/Axes**：画布和绘图区域的层次结构
- **图表类型**：折线图、散点图、柱状图、热力图、饼图等
- **输出格式**：PNG、PDF、SVG 等多种格式
- **生态**：Seaborn、Plotly 等库的底层基础
