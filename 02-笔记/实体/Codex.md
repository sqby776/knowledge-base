# Codex

## 定义

Codex（OpenAI Codex CLI）— OpenAI 推出的编码 Agent，通过命令行界面让 AI 直接与代码仓库交互，实现代码生成、修改和审查。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **CLI 驱动** | 命令行界面，与 Git 仓库集成 |
| **代码修改** | 直接编辑、创建和删除文件 |
| **代码审查** | 自动 PR 审查 |
| **功能开发** | 从需求到实现的端到端开发 |
