# all-MiniLM-L6-v2

## 定义

all-MiniLM-L6-v2 — Sentence Transformers 系列轻量向量嵌入模型，384 维输出，在性能和效果之间取得良好平衡。广泛用于语义搜索和文本相似度计算。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **轻量** | 仅 80MB 模型大小 |
| **384 维** | 适中的向量维度，权衡速度和精度 |
| **多语言** | 支持中文等语言 |
| **高吞吐** | 推理速度快，适合大规模文档嵌入 |

## 在本系统中的用途

- ChromaDB 向量ittion 嵌入
- 知识库语义搜索
- 记忆系统向量化
