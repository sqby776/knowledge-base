# 网页抓取

## 定义

网页抓取（Web Scraping）— 从网站页面自动提取数据的各类技术方案总称，涵盖轻量请求库到完整浏览器自动化。

## 常用方案

| 方案 | 定位 | 适用场景 |
|:-----|:-----|:---------|
| **curl / requests** | 简单 HTTP 请求 | 静态页面、API 接口 |
| **Camoufox** | 反检测浏览器自动化 | 复杂 JS 渲染、反爬严格站点 |
| **crawl4ai** | 通用网页抓取框架 | 批量抓取、结构化数据提取 |
| **Scrapling** | 自适应爬虫框架 | 需要灵活 CSS/XPath 选择器 |
| **Playwright** | 完整浏览器自动化 | 需要与页面交互（点击、表单） |
| **Tesseract OCR** | 图片文字提取 | 图片验证码、PDF 扫描件 |

## 本系统使用的工具

- [[Camoufox]] — 反检测浏览器，绕 Cloudflare
- [[crawl4ai]] — 通用抓取框架，指令提取
- [[Scrapling]] — 自适应爬虫，StealthyFetcher
- [[TesseractOCR]] — OCR 辅助文字提取
- browser-harness — AI 浏览器自动化工具
