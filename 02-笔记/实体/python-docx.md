# python-docx

## 概览

Python 库，用于创建和修改 Microsoft Word (.docx) 文件。

## 关键信息

- **用途**：自动化生成 Word 文档
- **核心对象**：Document、Paragraph、Run、Table
- **适用场景**：批量生成报告、合同、文档模板填充
