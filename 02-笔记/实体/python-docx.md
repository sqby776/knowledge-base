# python-docx

## 定义

python-docx — Python 读写 Microsoft Word .docx 文件的库，支持文本、表格、图片、样式、页眉页脚等。

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| **读写文档** | 创建和修改 .docx 文件 |
| **文本样式** | 字体、字号、颜色、加粗、斜体 |
| **段落格式** | 对齐、缩进、行距、段前段后 |
| **表格** | 创建、合并、样式设置 |
| **图片** | 插入图片，调整大小位置 |
| **页眉页脚** | 每节独立设置 |

## 在本系统中的用途

- 公文生成（符合 GB/T 9704-2012 标准）
- 工资表导出到 Word
- 自动化报告生成
