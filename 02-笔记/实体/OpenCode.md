# OpenCode

## 定义

OpenCode — 开源 AI 编码 Agent CLI，支持代码审查、功能开发和文档生成，可直接在终端中与代码库交互。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **代码审查** | 自动审查 PR 并提供修改建议 |
| **功能开发** | 从描述生成完整功能实现 |
| **文档生成** | 自动生成项目文档和代码注释 |
| **轻量部署** | 相比 OpenHands 更轻量 |
