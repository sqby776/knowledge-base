# Chroma

## 定义

Chroma（ChromaDB）—— 开源向量数据库，用于存储和检索文本/图像的向量嵌入。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **开源免费** | 无需 API Key，本地部署 |
| **简单易用** | Python API 友好 |
| **持久存储** | 数据本地保存，重启不丢失 |
| **语义搜索** | 基于向量相似度的检索 |

## 技术架构

```
输入文本
    ↓
嵌入模型（如 all-MiniLM-L6-v2）
    ↓
生成向量（768 维）
    ↓
存入 ChromaDB
    ↓
检索时：查询向量 → 相似度排序 → 返回结果
```

## 在本系统中的作用

| 用途 | 说明 |
|:-----|:-----|
| **记忆存储** | MemOS 的向量存储后端 |
| **知识库检索** | RAG 的检索源 |
| **语义搜索** | 超越关键词的语义匹配 |

## 安装配置

```bash
pip install chromadb
```

## 与向量数据库对比

| 数据库 | 特点 | 适用场景 |
|:-------|:-----|:-----|
| **Chroma** | 轻量、本地、开源 | 个人知识库、本地 RAG |
| **Milvus** | 高性能、分布式 | 大规模生产环境 |
| **Pinecone** | 托管服务、易用 | 快速原型 |
| **Qdrant** | Rust 编写、高性能 | 生产环境 |
