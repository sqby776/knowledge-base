# python-pptx

## 定义

python-pptx — Python 读写 Microsoft PowerPoint .pptx 文件的库，支持幻灯片创建、文本框、表格、图表、图片等。

## 核心功能

| 功能 | 说明 |
|:-----|:-----|
| **创建幻灯片** | 添加、删除、复制幻灯片 |
| **文本内容** | 文本框、段落、字体样式 |
| **形状** | 插入矩形、圆形、箭头等形状 |
| **表格** | 创建和格式化表格 |
| **图表** | 插入柱状图、折线图等图表 |
| **母版** | 使用和自定义幻灯片母版 |
