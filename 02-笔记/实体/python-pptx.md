# python-pptx

## 概览

Python 库，用于创建和更新 Microsoft PowerPoint (.pptx) 文件。

## 关键信息

- **用途**：自动化生成演示文稿
- **核心对象**：Presentation、Slide、Shapes、TextFrame、Table
- **适用场景**：批量生成报表演示、自动化工具输出
