# 浏览器自动化插件安装指南

> 来源：PHP 中文网 - 星夢妙者
> 发布日期：2026-04-27

## 摘要

需依次完成 Node.js v22 安装、启用 browser_automation 插件、手动安装 Puppeteer/Playwright 驱动、配置系统浏览器权限，并通过截图指令验证功能就绪。

## 一、确认并安装 Node.js 运行时

浏览器自动化依赖 Node.js v22 提供 Puppeteer 与 Playwright 底层支持，Hermes Agent 默认不自带该环境，需独立验证并补全。

### 步骤

1. 检查当前 Node.js 版本：
   ```bash
   node --version
   ```

2. 若返回错误或版本低于 v22.0.0，访问 https://nodejs.org/dist/ 下载并安装 Node.js v22.x LTS 版本。

3. 安装完成后重新打开终端，再次运行：
   ```bash
   node --version
   npm --version
   ```
   确认两者均正常输出。

> **当前状态**：你已配置 Node.js v24.16.0 ✅

## 二、启用内置浏览器自动化插件

Hermes Agent 通过插件机制管理浏览器能力，默认不自动激活。

### 步骤

1. 进入交互式插件配置界面：
   ```bash
   hermes tools
   ```

2. 使用方向键导航至 `browser_automation` 选项，按空格键勾选启用。

3. 按回车确认提交，等待显示 `Plugin browser_automation loaded successfully`。

4. 验证：
   ```bash
   hermes config get tools.browser_automation.enabled
   ```
   返回值为 `"true"`。

## 三、手动安装 Puppeteer 或 Playwright 驱动

当网络受限或国内镜像未生效时，自动安装可能失败，导致浏览器实例启动报错 `no browser found`。

### 步骤

1. 进入 Hermes Agent 虚拟环境，获取安装路径：
   ```bash
   pip show hermes-agent
   ```

2. 切换至 `site-packages/hermes_agent/plugins/browser_automation/` 目录。

3. 使用淘宝镜像强制安装 Puppeteer：
   ```bash
   PUPPETEER_DOWNLOAD_HOST=https://npmmirror.com/mirrors npm install puppeteer@22.5.0
   ```

4. 若选用 Playwright：
   ```bash
   PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors npx playwright install chromium
   ```

## 四、配置系统级浏览器权限

macOS Gatekeeper 与 Windows SmartScreen 会拦截未经签名的自动化浏览器进程。

### macOS

1. 打开"访达"，进入 `/Applications/Chromium.app` 或对应浏览器应用目录。
2. 右键点击应用图标，选择"显示简介"，勾选底部"仍要打开"选项。

### Windows

1. 首次运行时若弹出 SmartScreen 警告，点击"更多信息" → "仍要运行"。
2. 重启 Hermes Agent 服务使权限变更生效。

> **当前环境**：Linux Ubuntu 24.04，无需此步骤 ✅

## 五、验证插件功能是否就绪

### 步骤

1. 启动交互终端：
   ```bash
   hermes
   ```

2. 输入指令：
   ```
   请打开 https://example.com 并截图首页，保存为 screenshot.png
   ```

3. 观察终端是否输出 `[browser] launched chromium with pid XXXX` 及后续截图成功提示。

4. 检查当前目录是否生成 `screenshot.png` 文件，且图像内容可正常查看。

## 补充说明

本文提到的 `browser_automation` 插件是 Hermes Agent 内置的浏览器自动化工具，与当前使用的 **browser-harness** 是两套不同方案：

| 方案 | 协议 | 语言 | 状态 |
|:-----|:-----|:-----|:-----|
| browser_automation (内置) | Puppeteer/Playwright | Python + Node.js | 需手动启用 |
| browser-harness | CDP 直连 | Python | ✅ 已安装验证 |

**建议**：两套方案功能重叠，建议**二选一**，避免维护负担。
