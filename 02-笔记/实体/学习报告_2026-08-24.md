## 二、核心功能更新

### 🔥 v0.20.5 主要特性

**1. Bot Mode 增强**
- 群聊线程支持
- 可折叠对话摘要
- blob-face 头像系统
- @mention 标签功能修复

**2. 关键网页层 (Keyless Web Tier)**
- 5 供应商轮换策略 (Tavily, Firecrawl, Keenable 等新加入)
- Ring failover 机制
- 首次安装无需 API Key 即可使用网页搜索

**3. CLI 体验改进**
- 模糊 `/model` 选择器
- Ctrl+P 命令面板
- 更丰富的 `/status` 输出

**4. 执行纪律优化**
- 运行时停滞保护 (来自 Composio 评估发现)
- 重复调用去重为引用 stubs

**5. 桌面版性能**
- 渲染优先策略
- 合成器加载指示器
- React Compiler 集成
- 主题系统优化 (glass effect, accent picker)

**6. Cron 作业增强**
- 持久化记忆
- 每作业推理强度配置

## 五、关键决策点

### 关于 `fallback_providers`

系统当前配置：`fallback_providers` 已清空，仅提示限速不自动切换模型。这是用户明确偏好，需保持。

### 关于模型提供商

- 当前使用 Sensenova API (token.sensenova.cn)
- 支持 OpenAI 兼容接口
- 支持本地模型 (Ollama, vLLM, llama.cpp, SGLang)

## 六、值得关注的更新

### 重大架构变化

1. **Keyless Web Tier**: 无 API Key 即可使用网页搜索，5供应商轮换
2. **Bot Mode 群聊线程**: 多线程协作能力
3. **Desktop React Compiler**: 渲染性能提升

### 值得注意的改动

- `hermes worktree list/prune` 新增工作树管理
- `hermes update` 增加收据验证
- 桌面版 Glass effect 主题系统
- 主题accent颜色自定义插件

## 七、学习建议

1. **关注版本更新**: 目前版本迭代速度快 (每周都有小版本)，建议定期同步

3. **Bot Mode 进阶**: 如需多Agent协作，可深入研究群聊线程功能
4. **桌面版优化**: 如使用桌面版，可关注 React Compiler 带来的性能提升
