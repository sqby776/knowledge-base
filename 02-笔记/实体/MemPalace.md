# MemPalace

## 定义

MemPalace（记忆宫殿）—— 基于 MemOS 的本地记忆管理系统，提供结构化的记忆存储和检索能力。

## 核心概念

| 概念 | 说明 |
|:-----|:-----|
| **记忆宫殿** | 结构化的记忆存储体系 |
| **智能去重** | 自动识别重复/更新/全新内容 |
| **混合检索** | 多策略融合的检索机制 |

## 与 MemOS 的关系

- **MemOS** 是底层记忆操作系统
- **MemPalace** 是基于 MemOS 的记忆管理方案
- 两者通常一起使用

## 记忆类型

| 类型 | 存储位置 | 用途 |
|:-----|:-----|:-----|
| **热记忆** | MEMORY.md | 核心信息，快速访问 |
| **冷记忆** | ChromaDB | 详细知识，语义检索 |
| **知识图谱** | SQLite | 实体关系三元组 |
| **会话记忆** | session_search | 历史对话检索 |

## 使用流程

```
新信息进入
    ↓
MemOS 智能去重
    ↓
判断：重复/更新/全新
    ↓
重复 → 忽略
更新 → 更新现有记忆
全新 → 存入记忆宫殿
    ↓
更新索引
```
