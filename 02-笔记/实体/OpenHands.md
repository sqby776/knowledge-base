# OpenHands

## 定义

OpenHands（原名 OpenDevin）— 开源 AI 编码 Agent 平台，7.4 万+ GitHub Stars。让 AI 直接操作代码编辑器、终端和浏览器来开发软件。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **代码操作** | AI 直接编辑文件、运行命令、管理项目 |
| **沙箱环境** | 安全隔离的运行容器 |
| **多后端** | 支持多种 LLM 模型 |
| **浏览器集成** | 可直接操作浏览器进行测试和验证 |

## 与本系统关系

Hermes Agent 可与 OpenHands 集成使用：
- Hermes 负责编排和自动化流程
- OpenHands 专注代码层面的修改和开发
- 两者互补而非替代
