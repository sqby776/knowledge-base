# GitHub 5月星标暴涨的6个开源项目，第4个我直接部署了

Original  三带俩王 向上生长指南书

数据截止 5 月 26 日，每个都拉过 GitHub API ，不是靠印象写的。

## 1. mattpocock/skills —— 10.5 万星

⭐ 105,710 | Shell | 创建于 2026 年 2 月

Matt Pocock 把自己 `.claude` 目录里的所有配置开源了——让 Claude Code 从"凑合能用的助手"变成"真能帮你干活的搭档"的秘密配方。一套给 AI 编程助手的技能包。

包含：生成 commit message、写 changelog、PR review 模板、单元测试自动补全。每个技能就是一个 markdown 文件，可以直接抄或魔改。

适合：重度 Claude Code 用户。五分钟见效，没有任何依赖。

## 2. rtk-ai/rtk —— 5.4 万星

⭐ 54,205 | Rust | 创建于 2026 年 1 月

解决 AI 编程工具太费 token 的问题。它是一个 CLI 代理——夹在你和 AI 编程助手之间，拦截重复的、低价值的请求，只把真正需要 LLM 处理的命令传过去。

一个 Rust 二进制，零依赖。创始人给的数据是 60%-90% 的 token 削减，多数人跑出来在 50%-70% 之间。重度用户一个月能省几百块。

争议：有时该重跑的东西被缓存了，导致上下文"过时"。但思想方向没错——LLM 调用不应该默认走全量，缓存和去重应该做在系统层。

适合：每天跟 AI 编程助手耗 token 耗到心疼的人。

## 3. datawhalechina/hello-agents —— 5.3 万星

⭐ 53,494 | Python | 创建于 2025 年 9 月

Datawhale 出的《从零开始构建智能体》，是目前中文 Agent 教程里信息密度最高的一本——不是"AI Agent 科普五分钟"式内容，是真的一章一章带你手写代码。

从最基础的 LLM 调用，到 RAG，到多 Agent 协作，全链路覆盖。配套的 GitHub repo 里有完整的 Jupyter Notebook、数据集、课后练习。

适合：想系统学 AI Agent 开发的，Python 基础够用的。

## 4. hugohe3/ppt-master —— 2.1 万星

⭐ 21,105 | Python | 创建于 2025 年 12 月

一句话生成可编辑的 PPTX。生成的是原生 PowerPoint 元素——文本框、形状、图表，全部可编辑。不是图片。

支持从 Markdown、Word、PDF、甚至一个 URL 生成 PPT。

瑕疵：复杂图表搞不定（饼图勉强，散点图摆烂）。生成的文本框有时候会叠在一起。

适合：每周要做汇报但不爱做 PPT 的人。普通办公场景够用，专业设计场景不够。

## 5. ruvnet/wifi-densepose —— 6.6 万星

⭐ 66,003 | Rust | 创建于 2025 年 6 月

把 WiFi 信号变成人体追踪。原理：人体会吸收和反射 WiFi 信号，通过信号变化推算一个人的姿势、位置、甚至心率。

不需要摄像头。不需要雷达。就靠路由器。

精度取决于 WiFi 设备密度——家里一个路由器只能告诉你"有人在动"，商用场景（商场/办公室布满 AP）可以达到厘米级定位。

应用场景：隐私监控、智能家居无感交互、养老院跌倒检测。

适合：搞 IoT、边缘计算、智能硬件的。

## 6. CloakHQ/[[CloakBrowser vs camofox-browser：反检测浏览器选型对比_学习要点.md]] —— 2.1 万星

⭐ 21,113 | Python | 创建于 2026 年 2 月

打了底层补丁的 Chromium，直接在源码级处理浏览器指纹：WebGL、Canvas、字体、navigator 对象——所有检测脚本用来判断"这是真人还是机器人"的信号，它全伪装了。

官方说法是 30/30 测试全过。Cloudflare 和 Datadome 都能绕。是 Playwright 的直接替代。

适合：经常需要自动化抓取、测试、数据采集的。注意合法合规使用。

## 评价标准

好项目不是看 star 数最高的，是看能不能五分钟装好、十五分钟用上。

mattpocock/skills、rtk、ppt-master 三样是普通人今天就能用起来的。hello-agents 需要投入学习时间但值得。wifi-densepose 适合硬件方向的技术储备。[[CloakBrowser vs camofox-browser：反检测浏览器选型对比_学习要点.md]] 用到的场景会越来越频繁。
