# MOC（Map of Content）

## 定义

MOC（Map of Content，主题地图）—— 一种知识导航结构，用于组织和引导读者理解某个主题领域的知识体系。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **不是目录** | MOC 是理解路线图，不是简单的文件列表 |
| **主题导向** | 按主题/领域组织，而非按时间/文件类型 |
| **层级结构** | 可包含子 MOC，形成树状导航 |
| **动态更新** | 随知识库扩展而更新 |

## MOC 的作用

```
用户进入知识库
    ↓
查看 MOC（主题地图）
    ↓
了解知识体系结构
    ↓
选择感兴趣的主题
    ↓
深入阅读相关页面
```

## MOC 的类型

| 类型 | 用途 | 示例 |
|:-----|:-----|:-----|
| **全局 MOC** | 整个知识库的导航 | `知识库地图.md` |
| **领域 MOC** | 某个领域的导航 | `AI 技术地图.md` |
| **项目 MOC** | 某个项目的导航 | `Hermes 技能地图.md` |

## 编写规范

```markdown
# 主题地图名称

## 阅读顺序

入门 → 核心概念 → 工具配置 → 进阶
  ↓        ↓           ↓          ↓
README   RAG        Hermes      知识飞轮

## 核心模块

### 1. 基础篇
- [[RAG]] — 说明
- [[主题地图]] — 说明

### 2. 进阶篇
- [[知识飞轮]] — 说明
```

## 与 index.md 的区别

| 文件 | 用途 |
|:-----|:-----|
| `index.md` | 总入口，列出所有重要页面 |
| `MOC` | 主题导航，引导理解路径 |
