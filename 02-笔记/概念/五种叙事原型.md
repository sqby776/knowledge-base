# 五种叙事原型

> 公众号长文结构归纳

## 说明

大部分文章的结构是重复的。归纳成五种原型，动笔前先判断属于哪个原型。

## 五种原型

| 类型 | 结构重心 | 适用场景 |
|:-----|:---------|:---------|
| **产品体验型** | 感官故事破冰 → 产品逻辑收尾 | 产品评测、使用体验 |
| **热点复盘型** | 先给结论 → 事件时间线复盘 | 热点事件分析 |
| **人物故事型** | 性格切片 → 事件 → 归因 | 人物专访、故事叙述 |
| **方法论型** | 痛点 → 方法 → 案例 | 教程、经验分享 |
| **观点对冲型** | 对立观点 → 逐层拆解 → 立场 | 争议话题、观点输出 |

## 使用建议

每次动笔前，先判断属于哪个原型，然后按对应的重心来写。不是每次都要从零发明轮子。
