# 知识飞轮

## 定义

知识飞轮（Knowledge Flywheel）—— 一种知识自我进化的机制，通过持续的信息获取、编译、存储、反馈形成闭环，使知识库越来越丰富和精准。

## 飞轮原理

```
┌─────────────────────────────────────────────────────────────┐
│                      知识飞轮                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   信息获取 ──→ 知识编译 ──→ 知识存储 ──→ 反馈应用           │
│      ↑                                   │                  │
│      │                                   ↓                  │
│      └────────────── 优化改进 ←──────────┘                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 四个环节

### 1. 信息获取

| 方式 | 工具 |
|:-----|:-----|
| 网页抓取 | Camoufox, crawl4ai, scrapling |
| 手动输入 | 复制粘贴、截图 OCR |
| 自动订阅 | RSS、Cron Job 定时抓取 |

### 2. 知识编译

| 任务 | 说明 |
|:-----|:-----|
| 提取核心概念 | 识别文章中的关键知识点 |
| 创建知识节点 | 生成概念页/实体页 |
| 建立双链关联 | 使用 `[[wikilink]]` 连接相关页面 |
| 更新 MOC | 调整主题地图结构 |

### 3. 知识存储

| 存储位置 | 用途 |
|:---------|:-----|
| `01-收件箱/` | 原始资料（只追加） |
| `02-笔记/` | 长期知识节点 |
| `07-地图/` | 主题地图 |

### 4. 反馈应用

| 场景 | 说明 |
|:-----|:-----|
| RAG 检索 | 基于知识库生成答案 |
| 日常查询 | 快速查找信息 |
| 内容创作 | 基于知识节点生成文章 |

## 飞轮加速

| 加速方式 | 说明 |
|:---------|:-----|
| **自动化** | 用 Hermes Cron 自动抓取 + 编译 |
| **双链增强** | 更多双链 = 更强检索能力 |
| **反馈循环** | 使用越多 → 优化越多 → 更好用 |

## 与 LLM Wiki 的关系

- **LLM Wiki** 是知识组织形态
- **知识飞轮** 是知识进化机制
- 两者结合形成自进化的知识系统
