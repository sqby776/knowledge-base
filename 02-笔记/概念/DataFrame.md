# DataFrame

## 概览

pandas 的核心二维数据结构，类似 SQL 表或 Excel 表格，行带索引，列带名称。

## 关键信息

- **构造**：可从字典、NumPy 数组、CSV、列表等创建
- **每列独立 dtype**：这是与 NumPy 数组的核心差异
- **索引**：支持标签索引（loc）和位置索引（iloc）
- **核心操作**：选择、过滤、排序、分组、合并、重塑
- **适用场景**：数据清洗、数据分析、数据转换
