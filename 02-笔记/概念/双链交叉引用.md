# 双链交叉引用

## 定义

双链交叉引用（Bidirectional Linking）—— 知识管理中的一种链接机制，页面 A 链接到页面 B 时，页面 B 自动记录反向链接到页面 A。

## 核心机制

```
页面 A: 提到 [[本地知识库]]
    ↓
页面 B: 自动显示"被页面 A 链接"
    ↓
形成双向关联
```

## 实现方式

| 平台 | 实现 |
|:-----|:-----|
| **Obsidian** | `[[RAG]]` 自动创建双向链接 |
| **Logseq** | 原生支持双链 |
| **Notion** | 需手动维护反向链接 |
| **Roam Research** | 原生支持双链 |

## 双链的价值

| 价值 | 说明 |
|:-----|:-----|
| **知识关联** | 发现概念之间的联系 |
| **图谱可视化** | 通过 Graph View 查看知识网络 |
| **反向查找** | 快速找到引用当前页面的所有位置 |
| **网络效应** | 链接越多 → 价值越大 |

## 使用规范

### 必须使用双链的场景

- 重要概念首次出现时
- 引用其他页面内容时
- 跨主题关联时

### 双链格式

```markdown
# 正确
参考 [[RAG]] 技术实现
详见 [[Hermes-Agent]] 文档

# 不正确（应避免）
参考 RAG 技术实现
详见 Hermes Agent 文档
```

## 与知识网络的关系

```
单个双链 = 一条边
多个双链 = 知识网络
双链密度高 = 知识网络紧密
```

## 常见问题

| 问题 | 解决方案 |
|:-----|:-----|
| 链接到不存在的页面 | 创建对应页面或移除链接 |
| 链接过多导致混乱 | 按 SCHEMA 规范分类 |
| 链接断裂 | 定期检查和修复 |
