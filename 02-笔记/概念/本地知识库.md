# 本地知识库

## 定义

本地知识库（Local Knowledge Base）—— 存储在本地文件系统上的知识集合，以 Markdown 文件为主要格式，支持双链关联和版本控制。

## 核心特点

| 特点 | 说明 |
|:-----|:-----|
| **本地存储** | 文件存储在本地，不依赖云端服务 |
| **Markdown 格式** | 纯文本，易读易编辑，跨平台兼容 |
| **双链关联** | 页面之间通过 `[[双向链接]]` 相互关联 |
| **版本控制** | 可用 Git 进行版本管理和备份 |

## 与云端知识库对比

| 维度 | 本地知识库 | 云端知识库 |
|:-----|:-----|:-----|
| **数据主权** | 完全掌控 | 依赖服务商 |
| **离线使用** | ✅ 完全支持 | ❌ 需联网 |
| **迁移成本** | 低（纯文本） | 高（平台锁定） |
| **隐私安全** | 高 | 取决于服务商 |
| **同步方式** | 手动/Git | 自动 |

## 典型实现

| 工具 | 特点 |
|:-----|:-----|
| **Obsidian** | 本地双链笔记，插件生态丰富 |
| **Logseq** | 本地大纲笔记，原生双链 |
| **Joplin** | 本地笔记，支持加密 |

## 本系统实现

```
~/workspace/knowledge/
├── SCHEMA.md          # 规则文件
├── index.md           # 总入口
├── log.md             # 更新日志
├── 01-收件箱/          # 原始资料
├── 02-笔记/          # 知识节点
├── 07-地图/            # 主题地图
└── .git/              # Git 版本控制
```

## 优势

1. **数据可控** — 文件在自己手中，不担心服务商倒闭
2. **长期可用** — Markdown 是开放格式，几十年后仍能打开
3. **灵活扩展** — 可自由添加脚本、工具、自动化
4. **隐私安全** — 敏感内容无需上传云端
