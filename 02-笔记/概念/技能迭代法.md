# Skill 迭代法

> AI 辅助写作技能进化方法

## 说明

Skill 是靠喂出来的，不是想出来的。通过对比迭代让 Skill 不断进化。

## 迭代循环

```
旧文章（参照物）→ AI 按 Skill 写新文章 → 逐段对比 → 记录优劣 → 更新 Skill → 再测
```

## 迭代步骤

1. **找参照物**：拿一篇自己满意的旧文章
2. **跑新文章**：让 AI 按当前 Skill 写一篇新的
3. **逐段对比**：好的地方记下来，不好的地方也记下来
4. **更新 Skill**：根据对比结果修改 SKILL.md
5. **再测**：用新 Skill 再跑一轮

## 版本演进

| 版本 | 满意率 | 说明 |
|:-----|:-------|:-----|
| v1.0 | 低 | 差得一塌糊涂，但跑起来了 |
| v1.3 | ~80% | 只需要小改，不用大改 |

## 核心价值

最有价值的部分不是 Skill 本身，是「对比迭代」这个动作。对照着自己的标准去判断什么好什么不好，比看一百篇写作教程都有用。
