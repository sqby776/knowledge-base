# 工资系统安全架构

## 核心原则

1. **分层防御**：每个安全威胁至少有两层防护
2. **白名单制**：允许的安全操作 > 阻止的危险操作
3. **纵深防护**：前端→路由→ORM→存储，每层都校验

## 公式引擎安全（P0 最高优先级）

### 代码注入防护

```python
# ❌ 危险：原生 eval() 可执行任意代码
row[h] = float(eval(_expr))

# ✅ 安全：simple_eval 白名单引擎
from simpleeval import simple_eval, NameNotDefined
try:
    row[h] = float(simple_eval(expr, functions={}, names={}, allowed_attrs=[]))
except (NameNotDefined, ZeroDivisionError, TypeError, ValueError):
    row[h] = 0.0
```

**参数说明**（兼容 simpleeval 0.9.x ~ 1.x）：

| 参数 | 作用 | 阻止的攻击 |
|------|------|-----------|
| `functions={}` | 禁用所有函数调用 | `__import__`、`open`、`eval` |
| `names={}` | 禁用内置变量 | 无变量注入 |
| `allowed_attrs=[]` | 封锁属性访问 | `().__class__.__bases__` 链 |

**注意**：`builtins=[]` 在 simpleeval 0.9.x 和 1.x 中均不支持。

**验证**：
```python
simple_eval("().__class__.__bases__[0].__subclasses__()",
    functions={}, names={}, allowed_attrs=[])
# 应抛出 FeatureNotAvailable
```

## SQL 注入防护

### ❌ NEVER: f-string + text()

```python
# 危险：变量哪怕"是整数"，f-string 拼接也打破参数化边界
rows = db.session.execute(text(f"SELECT * FROM t WHERE year={year}"))
```

### ✅ ALWAYS: 参数化绑定

```python
rows = db.session.execute(
    text("SELECT * FROM t WHERE year=:year AND month=:month"),
    {'year': year, 'month': month}
).fetchall()
```

**排查**：
```bash
grep -rn '\.execute(.*f["'"]' blueprints/   # 找 f-string 拼接
```

## CSRF 防护

### 全局 before_request 拦截

```python
@app.before_request
def global_csrf_protect():
    if request.method in ('POST', 'PUT', 'DELETE'):
        if request.path.startswith('/api/'):
            return  # API 豁免
        if request.headers.get('X-Requested-With') == 'XMLHttpRequest':
            return  # AJAX 豁免
        token = request.form.get('csrf_token') or ''
        if not validate_csrf_token(token):
            return redirect(url_for('login'))
```

### 豁免条件（需要双重保护）

路由已有 `@login_required` + `@permission_required` = 可以从全局 CSRF 豁免。

**常规豁免白名单**：
- `/salary/` 下审核/退回/解锁
- `/modules/` 下计算/提交审核/复制

### 动态表单注入 CSRF Token

JS 创建的 `<form>` 无法预置 token，需手动从页面隐藏字段读取：

```javascript
var csrf = document.querySelector('[name="csrf_token"]');
var csrfVal = csrf ? csrf.value : '';
form.innerHTML = '<input name="csrf_token" value="' + csrfVal + '">'
    + '<input name="year" value="' + year + '">';
```

## XSS 防护

### Jinja2 自动转义陷阱

```jinja2
<!-- ❌ 自动转义破坏脚本 -->
<script>var data = {{ json_data }};</script>
<!-- 渲染为: var data = {&#34;key&#34;: &#34;val&#34;}; → SyntaxError -->

<!-- ✅ JSON 加 safe -->
<script>var data = {{ json_data|safe }};</script>
```

### 不要滥用 |safe 过滤器

```jinja2
<!-- ❌ 用户可编辑值加 safe -->
<td>{{ cell.val | safe }}</td>

<!-- ✅ 去掉 safe 用自动转义 -->
<td>{{ cell.val }}</td>
```

### innerHTML API 数据渲染

```javascript
// ❌ API 返回的数据拼接 innerHTML
title.innerHTML = '<i class="fas fa-table me-2"></i>' + moduleName;

// ✅ 用 createTextNode 安全插入
title.innerHTML = '<i class="fas fa-table me-2"></i>';
title.appendChild(document.createTextNode(moduleName));
```

## 文件上传安全

### 检查清单

- [ ] 扩展名白名单（仅 `.xlsx` / `.xls`）
- [ ] 用 `secure_filename()` 清理文件名
- [ ] `os.path.normpath()` + `startswith(SAFE_DIR)` 防止路径遍历
- [ ] 文件大小限制（`MAX_CONTENT_LENGTH` + 端点级校验）
- [ ] 删除时路径验证
- [ ] 上传后删除临时文件

```python
from werkzeug.utils import secure_filename

filename = secure_filename(upload_file.filename)
if not filename:
    flash('无效的文件名', 'danger')
    return redirect(...)
save_path = os.path.join(UPLOAD_DIR, filename)
upload_file.save(save_path)
```

### 路径遍历防护

```python
fpath = os.path.normpath(os.path.join(COVER_DIR, filename))
if not fpath.startswith(COVER_DIR):
    abort(400)
```

## 其他

### request.json 空值保护

```python
# ❌ request.json 为 None 时崩溃
value = request.json.get('key', '')

# ✅ 安全
data = request.json or {}
value = data.get('key', '')
```

### before_request 导包完整性

在 `before_request` 中引用 `session` / `g` / `flash` → **必须 import**。漏了导致所有请求 500。

**防御性写法**：
```python
@app.before_request
def my_handler():
    from flask import session  # 局部导入
    ...
```

### 会话超时

```python
app.config['PERMANENT_SESSION_LIFETIME'] = 1800  # 30分钟

@app.before_request
def check_session_timeout():
    if current_user.is_authenticated:
        last_active = session.get('_last_active')
        if last_active and (datetime.now().timestamp() - last_active) > 1800:
            logout_user()
            return redirect(url_for('login'))
        session['_last_active'] = datetime.now().timestamp()
```
