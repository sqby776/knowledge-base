## 可提取的新功能

### 1. code-wiki 技能 — 项目持久化开发维基
从文章：持久化代码库记忆
操作：`hermes skills install code-wiki`（已在技能列表中）
用途：自动为 hermes-agent 项目生成可搜索的开发维基

### 2. Web Dashboard — 系统状态可视化
从文章：web dashboards, runtime analytics
实现：Hermes 自带 Portal（`hermes portal`）
用途：通过浏览器查看 Agent 状态、任务进度、系统监控

### 3. 持久化 AI 助手（7×24）
从文章：fully persistent AI system
当前已有：Gateway 持续运行 + cron 定时任务
改进空间：增加无人值守的文件处理流程

### 4. Office自动化深度挖掘
从文章：business operations automation
✓ 合同审查 → 公文模板已有
✓ Google Slides 生成 → PPTX 生成已有
✓ workflow orchestration → Kanban 已有
改进：建立标准化的"公文处理看板流水线"

### 5. 研究系统增强
从文章：research ingestion pipelines, knowledge compounding
当前：每天3次编译 + 自动抓取
改进：新增收到新文章时的即时分析流程（本文已实现）
