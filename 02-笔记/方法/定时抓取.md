# 定时抓取

> [!SUCCESS] 全自动运行
> 每天早上 7:00 自动完成：抓取 → 入库 → 编译

## 工作流程

```
7:00 Cron → daily-capture.sh
              ↓
        auto-ingest.py (抓取网页)
              ↓
        01-收件箱/articles/ (原始内容)
              ↓
        auto-compile-fast.py (快速编译)
              ↓
        02-笔记/实体/ 或 概念/ (结构化知识)
```

## 配置

| 项目 | 值 |
|:-----|:-----|
| **脚本** | `~/workspace/scripts/daily-capture.sh` |
| **抓取脚本** | `~/workspace/scripts/auto-ingest.py` |
| **编译脚本** | `~/workspace/scripts/auto-compile-fast.py` |
| **Python 环境** | `~/office-venv` |
| **抓取目标** | Hermes Agent 官方文档 |
| **Cron 时间** | 每天 7:00 |

## 依赖

| 依赖 | 用途 |
|:-----|:-----|
| **crawl4ai** | 网页抓取引擎 |
| **Playwright Chromium** | 浏览器自动化 |
| **scrapling** | 轻量抓取备选 |

## 手动触发

```bash
# 完整流程（抓取 + 编译）
~/workspace/scripts/daily-capture.sh

# 仅抓取
~/office-venv/bin/python3 ~/workspace/scripts/auto-ingest.py "https://url" --category articles

# 仅编译
~/office-venv/bin/python3 ~/workspace/scripts/auto-compile-fast.py
```

## 日志

- 完整日志: `~/workspace/data/auto-daily.log`
- 抓取日志: `~/workspace/data/auto-capture-daily.log`

## 编译策略

| 模式 | 脚本 | 特点 |
|:-----|:-----|:-----|
| **快速编译** | `auto-compile-fast.py` | 规则-based，秒级完成 |
| **LLM 编译** | `auto-compile.py` | 深度分析，需 LLM（慢） |

当前使用快速编译模式，确保自动化流程不阻塞。
