# Hermes Agent 价值提升用法

> 来源：微信公众号「i 龙虾」，2026-05-26 抓取

## 核心观点

装上去然后用一用，是一种答案。但那种用法很快就会遇到天花板。真正的用法是：**设计一套让 Agent 持续工作的流程，而不是把它当成一个高级搜索框。**

## 五大价值提升用法

### 一、善用元提示优化/goal 命令

/goal 命令是 Hermes Agent 中执行长时间运行任务的核心功能，但多数人用法不当，效果不佳。

**问题**：问题不在于命令本身，而在于提示词质量。

**正确做法**：采用"元提示"
1. 先在普通对话中让 AI 帮自己生成一个适合/goal 使用的详细提示词
2. 将生成的提示词粘贴进/goal 执行

**案例**：以"用 Godot 做第三人称射击游戏"为例
- 直接使用简单提示 → 效果一般
- 让 AI 生成包含游戏机制、操控逻辑、场景结构、资产需求的完整提示词 → 产出真实可迭代的游戏原型框架

### 二、利用看板功能实现任务自动化

Hermes 看板功能被严重低估。

**操作流程**：
1. 通过仪表盘（`hermes dashboard`）进入 Kanban
2. 将任务放入"待分类"，自动分配给 Agent 执行，完成后归档

**晨间工作流**：
- 每天早上用纸列出当日事项
- 将"AI 能做的事"全部丢进看板
- 自己去处理必须人工完成的事务（打电话、付账单等）
- 返回时看板任务已在运行甚至完成

**核心差异**：普通任务管理软件提醒你自己去做，看板是真的把任务交给 AI 执行。

### 三、用 Agent 进行竞品技术拆解

**传统做法**：手动打开浏览器、逐层查看网络请求和 Console，耗时且效果有限。

**现在做法**：将提示词发给 Hermes，让其自动打开浏览器访问目标网站，进行完整技术调研：
- 分析技术栈、核心功能、前端框架
- 第三方服务与 API
- 付费功能定价逻辑
- 最终整理成 Markdown 报告

**后续**：拿到报告后可交给另一个 Agent 参考实现。

**核心**："拆解学习"而非"抄袭"，系统性地研究行业优秀产品，效率远高于自行摸索。

### 四、搭建记忆 Wiki 实现上下文积累

**问题**：使用 Hermes 时间长了，难以直观看到以往对话内容。

**解决方案**：让 Hermes 搭建一个本地网站，将每次对话的主题、完成的工作、讨论的想法分类整理。

**站点包含**：
1. 所有讨论过的主题列表（可点击查看详情）
2. 每日工作日志
3. 每个条目的对话记录和工作摘要

**价值**：
- 对用户本人：相当于一本自动维护的工作日记，可随时回溯
- 对 Agent 本身：设定每次工作前先查记忆 Wiki，使其带着上下文工作而非从零开始

**建议**：设置定时任务每天自动更新。

### 五、设置定时任务让 Agent 主动学习

**前四个用法**：用户主动使用 Hermes

**此用法**：让 Hermes 主动来找用户

**操作流程**：
- 设置定时任务：每天早上 9 点主动询问用户"今天最重要的一件事是什么"
- 根据回答列出可协助的相关任务
- 更新对用户记忆（目前在做什么、关注什么）

**价值**：积累效应
- 第一周：了解尚浅
- 三个月后：已清楚用户的项目、工作节奏、创作周期和瓶颈所在
- 这些信息积累会让 Agent 的建议越来越贴合实际

**案例**：若用户连续两周将"写文章"列为第一优先级，Agent 会主动在看板中预留相关任务模板。

## 总结

上述五个用法的核心在于：**设计一套让 Agent 持续工作的流程，而非将其当作高级搜索框偶尔使用。**

这五件事组合起来，真正意义上构建了一套 AI 协作系统，让 Hermes Agent 的价值从"偶尔问答"升级为"持续工作的 AI 员工"。
