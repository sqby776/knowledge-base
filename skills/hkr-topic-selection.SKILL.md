# HKR 选题质检

> 来源：《数字生命卡兹克文风复刻 skill 深度拆解》

## 原则

**S 级选题 = 三项兼备**
**及格选题 = 至少占两项**
只占一项或零项 → 主动调整方向或放弃。

---

## 三维度评分卡

动笔之前，对每个候选选题打分。

### ① Hot（热点性）

当前受众在讨论什么？蹭什么？

| 信号 | 判断 |
|------|------|
| 微博/知乎/朋友圈近期高频出现 | ✅ 有热点 |
| 行业有新闻事件、产品发布 | ✅ 有热点 |
| 话题已过气（超过 1-2 周无新讨论） | ❌ 无热点 |
| 纯自说自话，无人关注 | ❌ 无热点 |

### ② Related（关联性）

和你的人设/领域强相关吗？

| 信号 | 判断 |
|------|------|
| 选题和你过往内容方向一致 | ✅ 强相关 |
| 跨领域但有可迁移的角度 | ⚠️ 中等 |
| 完全无关，蹭流量而已 | ❌ 无关 |

### ③ Keen（锐度）

有反常识、反主流、个人独到的切入角度吗？

| 信号 | 判断 |
|------|------|
| 角度别人没讲过，或讲得不够深 | ✅ 有锐度 |
| 大众观点 + 你自己的一个补充视角 | ⚠️ 中等 |
| 纯粹搬运/复述别人说过的话 | ❌ 无锐度 |

---

## 评分规则

```
总分 = Hot + Related + Keen  （各 0-2 分）

3 分 → S 级，立即写
2 分 → A 级，可写（先调整两维度拉到更强）
1 分 → B 级，暂缓
0 分 → 放弃
```

---

## 常见错误

- **有热点 → 就写**：不看关联和锐度，写出来的东西都是流量口水文
- **有锐度 → 就写**：没有热点做引子，没人看得到
- **相关但无锐度**：安全但平庸，不会有人转发

---

## 快速自查（动笔前必答）

1. 这篇选题 **Hot 在哪**？（请写一句话描述当前热点窗口）
2. 这篇选题 **Related 在哪**？（和你哪个已有内容/领域相关？）
3. 这篇选题 **Keen 在哪**？（你的独特切入角度是什么？）

三个问题答不上来 → 不写，先攒素材。
